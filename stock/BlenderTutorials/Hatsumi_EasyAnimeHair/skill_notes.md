# Hatsumi「How to make EASY Anime Hair in Blender」Skill 化用ノート

出典: YouTube「How to make EASY Anime Hair in Blender」（Hatsumi、2026-04-10 公開、14:24、英語）。
凡例: 【話者】= 作者の意見・運用上の判断、【事実】= Blender の一般的な仕様、【画面】= 動画の画面で確認した値。聞き取りが不確かなものは「(要確認)」。時刻は動画内の時刻（説明文のチャプターと字幕の時刻に準拠）。
フレームは 6 枚のみ（うち 1 枚は無地）。画面で確認できた値は少なく、多くは口頭の値。

## 手法の位置づけ（房の作り方の分類）

- 【話者】カーブではなくメッシュで作る方法。Round Cube（丸い立方体）を頭にかぶせ、面を裂いて房に分ける
- 【事実】カーブ（ベベル深度とテーパーオブジェクト）で房を 1 本ずつ作る方法は、この動画では扱っていない
- 房の各要素と本動画での対応:
  - 形状: メッシュ。Round Cube を V（Rip）で裂く
  - 厚み（ベベルに相当）: Solidify モディファイアーを適用して作る
  - テーパー（毛先を細く）: 厚みの中央にループカット → 毛先の頂点を S で縮小
  - 法線: Mesh → Normals → Reset Vectors
  - マテリアル: 動画では扱わない（設定の説明なし）
- 【話者】初心者向け（「high beginner-friendly」）。単純な方法だが、複雑な髪を作るときの考え方のヒントになる（13:58〜）

## 前提・環境（00:11〜）

- 【画面】Blender 3.6.11（ステータスバー右下）
- Edit → Preferences → Add-ons → Community タブ → 「LoopTools」を検索して有効化 → 「Extra Objects」も有効化
- 【画面】Add Curve: Extra Objects と Add Mesh: Extra Objects の両方にチェック（00:41、frame_0002）
- 【画面】シーンには完成済みの頭のモデル（head）がある。髪はこれにかぶせて作る
- 【画面】ビューポート左上に「Centimeters」表示（06:29）。単位系がセンチメートル表示のシーン（Solidify の値の解釈に影響、要確認）

## 1. 土台の Round Cube（00:37〜）

- Shift+A → Mesh → Round Cube
- 【話者】Arc を 6、Linear を 1（00:50。Round Cube の Arc Divisions / Linear Divisions と思われる、正式な項目名は要確認）
- 【話者】約 0.90 まで縮める（00:53。Radius の値か S での拡大縮小か不明、要確認）
- 頭の形に合わせて調整

## 2. 前後に分けて左右対称にする（01:07〜）

- 後ろ半分を選択 → P で分離（【話者】「split the back half with P」。【事実】P は Separate。別オブジェクトになる）
- 【画面】アウトライナーに Roundcube、Roundcube.015、Roundcube.016 などが並ぶ（前髪と後ろ髪が別オブジェクト）
- 底面を削除。後ろ半分も同様
- 右側（片側）を削除 → 中央側の頂点を押し出してすき間を埋める
- 【画面】Mirror モディファイアー: Axis X、Clipping オン、Merge オン 0.001 m（06:29〜）
- 形を頭に合わせる → 縁の辺を選択 → LoopTools → Relax
- 少し下へ押し出す → プロポーショナル編集で丸みをつける
- スムーズシェードに切り替え（01:50）
- ループカットを数本追加（01:57）

## 3. 房に裂く・V 字の毛先（02:02〜）

- 房の半分くらいの高さまで面を選択 → V（Rip）→ マウスを横にずらして面を裂く（【話者】YouTube 字幕は「B」だが whisper と操作内容から V と判断）
- 【画面】ツールバーに Rip Region ツールがある
- 裂けた房の下側の頂点を少し下に引いて、とがった V 字にする（字幕の「B shape」は「V shape」）
- 【話者】好みで調整してよい。動画では簡単な形にとどめる
- 毛先に再度 V 字を作る → ループカットを追加 → 面を選んで V で裂く（02:51〜03:04）

## 4. 厚みと毛先の細め（03:19〜）

- Solidify モディファイアーを追加 → 厚み約 0.009（【話者】好みで変えてよい）→ 適用
- 厚みの中央にループカット → 毛先を選択して S で縮小（平たく細い毛先）
- 内側の頂点を Ctrl+クリックで選択 → Smooth Vertices。外側も同様（03:48〜）
  - 【事実】Ctrl+クリックは Pick Shortest Path（2 点間の最短経路を選択）
  - 【話者】Smooth Vertices はホットキーに割り当てているので右クリックメニューを出していない（EP0 では D キーと説明）

## 5. 法線（04:09〜）

- 全選択 → Mesh → Normals → Reset Vectors
  - 【話者】口頭では「face, normals」と言うが、【画面】テロップは「Mesh> Normals> Reset Vectors」（12:41、frame_0006）。Mesh メニューが正
  - 【話者】外側の辺がシャープになり、全体がなめらかに見える。好みなので不要なら省いてよい
  - 【画面】実行後の画面で外周の辺がシアン色（シャープ辺の表示）になっている（12:41）
  - 【事実】Reset Vectors はカスタム分割法線を消去して既定の法線に戻す操作。シャープ辺の付与そのものを行う機能ではないため、「シャープになる」の仕組みは要確認（Auto Smooth の設定と組み合わさった見え方の可能性）
- 見えない内側の面を削除して軽くする（04:29、【話者】最適化のため）
- 形を好みで調整 → 再度 Reset Vectors → 後ろ髪完成（04:53）

## 6. 前髪（05:00〜07:38）

- 後ろ髪と同じ方法: 片側を削除 → 中央へ押し出す → Round Cube を頭に合わせる → V で房に裂く
- 顔の横に長い房（フリンジ）を作る
  - ナイフ（K）で縦にまっすぐ切る → V 字に切る
  - 【話者】辺を分けても密度を上げすぎないため（05:52）
- 房の先にループカットを追加して調整
- 長い房: 下まで押し出す → プロポーショナル編集で回転 → ループカットを数本（06:28〜）
- 先端を縮めて三角形に → すき間を埋める（06:57）
- 面をもう 1 つ裂いて細部を足す（07:22）
- 【画面】前髪と長い房が完成した正面（07:35、frame_0004）

## 7. 前髪の仕上げ（07:38〜09:10）

- Solidify を追加 → 厚み 0.006 → 適用（【話者】YouTube 字幕は「0.006」、whisper は「00.6」。後ろ髪より薄い、要確認）
- 中央にループカット → 毛先を縮めて平たくする
- 【画面】毛先の Resize パネル（08:10、frame_0005）: Scale X/Y/Z 0.186、Orientation Global、Mirror Editing オン、Proportional Editing オン、Proportional Falloff Smooth、Proportional Size 0.000715、Connected オン
- 外側の頂点を Ctrl+クリック → Smooth Vertices。内側も同様
- 全選択 → Reset Vectors
- 外側の鋭く飛び出した部分を取る → 調整
- 中央の面をいくつか削除 → Reset Vectors → 完成（09:11）

## 8. サブディビジョンを使う場合（09:21〜）

- 【話者】Subdivision Surface モディファイアーを足してもよい。その場合、中央と下端の頂点に Shift+E でエッジクリースを入れ、分割前のとがった毛先を保つ
- 【話者】動画ではこのモディファイアーを足さない
- 【事実】Shift+E は Edge Crease。頂点ではなく辺に対する値（頂点クリースは別操作）。「middle vertices and bottom vertices」の対象は毛先の辺と思われる、要確認

## 9. ボーナス: 密度を上げる 2 つの方法（10:18〜）

- 方法 1: 髪の半分ほどを選択 → 複製（Shift+D）→ 分離 → 内側へずらして少し縮める（【話者】内側に 1 層足してボリュームを出す）
- 方法 2: 房の面を選択 → 複製 → 少し動かす → プロポーショナル編集で形を整える → 少し縮めて変化をつける（11:18〜）
- 足した房を土台とつなぐ手順（12:15〜）
  - 房の上側の面を削除
  - 土台側で、その真上の辺を選んで下へ裂く
  - V 字にする → 中央にナイフで切れ目
  - 房を土台につなぐ（【話者】「join」。オブジェクトの結合 Ctrl+J か頂点の接続かは不明、要確認）
  - Reset Vectors
  - 同じ手順を 2 か所で繰り返す（12:43〜13:07）
- 【話者】長い髪や細かい髪にも応用できる

## 判断基準・落とし穴

- 房に裂くのは房の半分くらいの高さまで。上まで裂くと頭頂部の面がばらばらになる（【話者】「halfway point」から推定、要確認）
- 切り込みを入れるときはナイフで V 字にして、辺を増やしすぎない
- Solidify は適用してから毛先の縮小と Smooth Vertices を行う（モディファイアーのままでは頂点を編集できない）
- 前髪は後ろ髪より薄くする（0.009 と 0.006）
- 形を変えたら Reset Vectors をかけ直す（動画では後ろ髪で 2 回、前髪でも 2 回実行）
- 見えない内側の面は削除して軽くする
- サブディビジョンを使うならクリースで毛先を守る
- Mirror モディファイアーの Clipping をオンにして中央の割れを防ぐ

## ショートカット早見

- Shift+A 追加 / P 分離 / V リップ / K ナイフ / S 拡大縮小 / Ctrl+クリック 最短経路選択
- Shift+D 複製（【事実】動画では口頭で「duplicate」とのみ）/ Shift+E エッジクリース
- Ctrl+R ループカット（【事実】動画では口頭で「loop cut」とのみ）/ O プロポーショナル編集（【事実】口頭のみ）
