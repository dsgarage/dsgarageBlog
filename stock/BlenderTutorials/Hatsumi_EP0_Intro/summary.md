# Hatsumi「Blender Vtuber Modeling Series: EP 0 Intro」要点

- VTuber モデルをゼロから作る連載の導入回（5:42）。方針・アドオン・よく使うツールを紹介する
- 全員が同じ 1 体を作るのではなく、配布される参照画像を改変したり自分の参照を使ったりして別々の完成形を目指す
- 肌の色・髪型・衣装・耳やしっぽなどを回ごとに複数用意し、男性版も作る予定。範囲はモデリングから Unity でのセットアップまで
- 作者の Blender は 3.6。バージョンは自由で、公式サイトか Steam から入手する
- 外部アドオンは VRM Add-on for Blender、Robust Weight Transfer、Mio3 UV（任意）、Ucupaint の 4 つ
- インストールは Preferences → Add-ons → Install で zip を解凍せずに選ぶ。同梱の LoopTools と Extra Objects も有効化して Save Preferences
- よく使うのは移動・拡大縮小・回転、Smooth Vertices（D キーに割り当て）、ベベル、ループカット、頂点スライド、Smooth / Grab ブラシ、プロポーショナル編集
- Overlays の Wireframe を常時オンにしておくのが作者の好み。参照画像とスターターメッシュは Patreon で無料配布
