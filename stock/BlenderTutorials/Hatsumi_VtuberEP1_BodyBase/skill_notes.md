# Hatsumi「VTuber Modeling Series EP1 Body Base」Skill 化用ノート

出典: YouTube「Blender Vtuber Modeling Series: EP 1 EASY Body Base Tutorial」（Hatsumi、2026-09-01 公開、19:23、英語）。
凡例: 【話者】= 作者の意見・運用上の判断、【事実】= Blender の一般的な仕様、【画面】= 動画の画面で確認した値。聞き取りが不確かなものは「(要確認)」。時刻は動画内の時刻。

## 前提・環境

- 【画面】Blender のバージョンは 3.6.11（ステータスバー右下）
- 【話者】VRM 用アドオン（VRM Add-on for Blender）を入れ、LoopTools を有効化しておく。LoopTools は多用する（00:15）
- 【事実】LoopTools の Circle は選んだ辺ループを円形に、Relax は間隔と形をならす。編集モードの右クリックメニューから呼べる
- 【話者】段階ごとの途中メッシュ（スターターメッシュ）と参照画像は作者の Patreon で配布。つまずいたらそこから再開してよい（04:49〜）
- 【画面】作者は工程の節目ごとにオブジェクトを複製して残している（アウトライナーに Cube.001〜Cube.008 が並ぶ）。Skill 化するなら工程ごとのスナップショット保存を手順に入れるとよい

## 1. 参照画像とスケール基準（00:30〜）

- 新規シーンでデフォルトの立方体は削除せず非表示（H）。後で体の材料にする
- Shift+A → VRM のアーマチュアを追加（大きさの基準にする）
- Shift+A → 参照画像（正面・側面が並んだ T ポーズ線画）を追加
- 【画面】画像エンプティ: Size 5 m、Opacity にチェックして 0.787 → 0.701 程度まで下げる（グリッドが透ける程度）
- 画像を後ろへ下げる。テンキー 3（右面ビュー）で同じ画像をもう 1 枚追加し、横にずらして正面図と輪郭の高さをそろえる。この段階では拡大縮小しない
- 側面図が Z 軸の中心に来るよう位置を戻す
- Shift+A → Empty → Plain Axes を追加（【画面】Display As: Plain Axes を確認。聞き取りは「plain axis」）
- 画像 → Shift+クリックでエンプティ → Ctrl+P でペアレント。もう 1 枚も同様
- エンプティを S で縮小し、画像をアーマチュアより少し低い程度にする
- 【話者】合わせる目安: 腕の線がアームボーンのすぐ下、腰がウエストのボーン上、両ひざの間隔がグリッド 1 マス
- 【話者】アーマチュアは縮尺の基準なので、画像を少し大きめにしてもよい

## 2. 胴体のベース（01:57〜）

- 立方体を再表示 → Subdivision Surface を 2 レベルで追加して適用
- 【画面】適用後: 頂点 98 / 面 96（02:26）
- 編集モードで S で全体を縮小 → 中央の水平ループが腰の高さに来るよう上へ移動
- 中央付近の頂点ループを選んで縮小し、他の段も縮小して胴体のシルエットにする（ループ選択の操作は聞き取りで「auto-click」。Alt+クリックと思われる、要確認）
- X-Ray をオン（参照画像を透かして見る）
- 右上の X ミラー（Mesh Symmetry の X、Mirror Editing）をオン
- テンキー 3 で右面 → メッシュを参照の中心へ移動（聞き取りは「Ctrl+A」。移動操作なので G の誤認識の可能性、要確認）
- 頂点の段ごとに Scale ツールで Y 軸方向に縮小し、体の厚みを側面参照に合わせる
- 【画面】画面左下に「S- Scale」などのキー名テロップが出る

## 3. 首（03:22〜）

- テンキー 1 で正面 → X-Ray のまま上面を選択 → E で押し出し ×2、そのつど S で縮小
- 最上部の中央 8 面を選択 → 右クリック → LoopTools → Circle → 面を削除（首の穴）
- 押し出して縮小 → X ミラーをオフにしてから、もう一度押し出して首を完成（X ミラーをオフにする理由は動画で明言なし、要確認）
- 【画面】首まで作った段階で胴体は縦長の円筒状（04:18、frame_0009）

## 4. スムーズと対称の修正（04:15〜）

- スカルプトモード → Smooth ブラシ → Strength を下げ、筆圧（Pressure）をオフ → メッシュ上を軽くクリックして角を取る
- 【画面】Smooth の Strength 0.248、Radius 86〜120 px
- 正面・編集モードに戻り、X ミラーをオンにして胸の位置に頂点をそろえる
- 【事実】ミラー編集で左右がずれたら、F3 検索で Snap to Symmetry を実行して対称に戻す

## 5. 胸（04:50〜）

- 胸の位置にそろえた 6 面を選択 → E で押し出し → 少し縮小
- Vertex メニュー → Smooth Vertices でならす
- 右面ビューで胸の形を側面参照に合わせる
- 中央にループカットを 1 本
- スカルプトモード → Grab ブラシで胸を前に引き出して形を出す
- 【画面】Grab の Strength 0.289、Radius 108 px 前後

## 6. ミラーモディファイアーへの切り替えと肩（06:03〜）

- メッシュの片側を選択して削除 → Mirror モディファイアーを追加
- 【画面】Mirror: Axis X、Merge オン 0.001 m。06:10 時点では Clipping オフ、06:38 以降はオン
- 【事実】Clipping をオンにすると中心線上の頂点がミラー面を越えなくなり、中央に隙間や重なりができにくい
- 首のつけ根付近の頂点を Move ツールで持ち上げる → 肩の土台（聞き取り「mold tool」は YouTube 字幕で「move tool」）
- ナイフ（K）で辺から中央まで切る → 三角面が 1 つできる（聞き取り「dry hair / try here」は「tri here」と判断）
- 2 点の間にループカットを入れる

## 7. 腕（07:00〜）

- 肩の横の中央 6 面を選択 → 押し出し → 少し縮小
- 上面を選択して同じ操作。上面の押し出しは合計 3 回
- 下側の 8 面を選択して削除 → 腕の付け根の穴
- プロポーショナル編集をオン → 上側の頂点を参照に合わせてドラッグし、角ばった穴を円形に近づける
- 【画面】Proportional Falloff: Smooth、Proportional Size 0.024（08:36）
- 【話者】腕の穴が大きくなりすぎないよう、下側の面を持ち上げておく
- 穴の縁の辺を選択 → 右クリック → LoopTools → Relax
- 押し出して腕を伸ばし、S → 軸 → 0 で断面を平らにそろえる（聞き取りは「Z 軸で 0」。腕は X 方向に伸びるので X 軸の可能性あり、要確認）
- 腕の中ほど（ひじのあたり）で辺を Ctrl+B でベベル → セグメント 2（聞き取り「bubble」は bevel）
- 【話者】セグメント 2 にするのは、リギング時の変形をきれいにするため
- 腕にループカットを数本追加
- 【画面】腕を押し出した状態（09:55、frame_0016）

## 8. 背中（09:59〜）

- 参照画像を非表示 → 背中の中央の辺を選んで少し内側へ押し込む
- 角ばりを減らす。必要ならスカルプトツールを使う

## 9. 腰まわり・脚の穴（10:56〜）

- スカルプトの Grab で胴体の底を少し平らにする
- 底面の外側の面を削除 → 脚の穴。中央部分は股になる
- 脚の穴の辺を選択 → LoopTools → Relax
- 【画面】Relax: Interpolation Cubic、Input Selection、Iterations 1、Regular オン（12:10）
- 下半分を選択して下へ移動
- 【話者】レオタードの形をイメージして頂点を並べる

## 10. 脚（12:03〜）

- 脚の穴の辺をループ選択（聞き取りは「Ctrl+click」。ループ選択なら Alt+クリック、要確認）→ 押し出して下へ → S Z 0 で断面を水平に
- お尻にあたる辺を選択 → Ctrl+B でベベル → お尻に丸みを出す
- ループカットを追加してお尻と太ももを分ける
- おなかにループカット → ナイフで既存の辺とつなぐ
- 頂点スライドで辺を下げる（【画面】テロップは「shift + v」。聞き取りの「Shift-B」は誤り）
- 【話者】肩と同じ要領で、脚の角ばりを減らして細部を作る。プロポーショナル編集が非常に役立つ
- 脚を押し出して縮小。ひざにループカットを追加
- 【話者】今は完璧でなくてよい。あとで戻って直せる
- ループカットをさらに追加 → スムーズシェード（聞き取りは「shade smooth」と「say it's smooth」で割れる、要確認）
- 右面ビューで脚の最後の辺を選択 → 影響範囲を大きくしたプロポーショナル編集で後ろへ押す → 脚全体がなだらかに追従
- 【事実】プロポーショナル編集の影響範囲は、変形中にマウスホイールで増減する
- 【画面】正面ワイヤーフレーム（15:12）: 頂点 408 / 面 380（ミラー適用前の片側分と思われる、要確認）

## 11. 任意のディテールと三角面の除去（15:12〜）

- 【話者】ここからは任意。より細部が欲しい場合のみ
- 胸の面を選択 → ベベル → つないで三角面を作る
- 【話者】あとでトポロジーを整理したくなったので、この三角面は最後に消す
- 全体を選択 → Smooth Vertices → サブディビジョンに頼らずなめらかなメッシュにする
- お尻の三角面: M → At Center で 2 点をマージ → 頂点を Dissolve → ループカットで三角面を解消
- 胸の三角面: ループカットを 1 本入れると消え、周囲がすべて四角面になる（18:06〜）
- 【画面】仕上げ時の寸法（頭と手足の先なし）: X 1.18 m / Y 0.245〜0.25 m / Z 1.38〜1.39 m（16:45〜18:31）

## 12. 仕上げの判断基準（16:54〜）

- 【話者】Grab で体を好みの形に整え続ける。参照に厳密に従うかは自由
- 【話者】Smooth Vertices でボリュームが減ったら、Grab で戻す
- 【話者】側面参照を 1 対 1 でなぞる必要はない。作者は背骨のカーブを参照より直線的にした
- 【話者】サブディビジョンを適用するかどうかは任意
- 【話者】これは体に慣れるためのごくシンプルなトポロジー。中級者なら自由に変えてよい
- 【話者】次回は手・足・頭

## 落とし穴・チェック項目

- X ミラーのオンオフを工程ごとに確認する。オフのまま左右を編集すると非対称になる（ずれたら Snap to Symmetry）
- 片側削除後は Mirror モディファイアーの Clipping をオンにして中心線の頂点を固定する
- 腕・脚の穴は大きくしすぎない。Relax をかけてから押し出す
- 押し出し直後は S → 軸 → 0 で断面をそろえる
- ひじ・ひざなど曲がる関節には辺を多めに入れる（リグの変形のため）
- 三角面ができたら、Merge・Dissolve・ループカットで四角面へ戻す
- Smooth Vertices は体積を減らすので、かけたあとに形を戻す
- 工程ごとにメッシュを複製して保存しておくと、失敗時に戻れる

- Ctrl+B ベベル / M マージ / Shift+V 頂点スライド / テンキー 1 正面・3 右面
- O プロポーショナル編集の切り替え（【事実】動画では口頭で「proportional editing enabled」とのみ）
