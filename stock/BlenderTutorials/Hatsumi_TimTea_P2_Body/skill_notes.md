# Hatsumi「TimTea P2 Body」Skill 化用ノート

出典: YouTube「Making A 3D Vtuber Avatar for TimTea! Part ~2 Body『Blender』」（Hatsumi、2023-07-28 公開、22:02、英語。ナレーションなし）。
凡例: 【話者】= 作者の意見・運用上の判断（説明文と画面テロップのみ）、【事実】= Blender の一般的な仕様、【画面】= 動画の画面で確認した値。画面から推測したものは「(要確認)」。時刻は動画内の時刻。
読み取り範囲: 抽出フレーム 63 枚（01:07〜21:40）のうち 30 枚。フレームの間の操作は見えていないため、手順の順番は推定を含む。

## 前提・環境

- 【画面】Blender 2.93.18（ステータスバー右下）
- 【画面】画面右上に、全身を映す小さな 3D ビューをもう 1 つ開いている。細部の編集中も全体のバランスを見られる
- 【画面】アウトライナーに eye / head / teeth / Circle / cowlic / ear / front bang / head.001 / head.002 / ponytail / side bang / sides / tail。第 1 回の Cube.00x から、部位名に名前が付け直されている
- 【話者】完璧にしたくて何度も取り消しと修正をした。男性キャラクターのトポロジーには慣れていない（説明文）

## 1. 参照画像の置き方（01:07〜）

- 【画面】参照は 3 種類: 顔のアップのイラスト、全身の正面イラスト、衣装設定をまとめた三面図
- 【画面】正面ビュー（Front Orthographic）で顔イラストと頭を重ね、首から下の輪郭を全身イラストに合わせる
- 【画面】三面図は斜めの板として横に置き、作業中に見返せる位置にある

## 2. 首から胴体を伸ばす（01:07〜04:12）

- 【画面】頭のオブジェクト head.002 の編集モードで、首の下に円筒状の胴体が伸びている（01:07、01:33）
- 【画面】Mirror: Axis X、Clipping オン、Merge オン 0.001 m
- 【画面】Loop Cut: Number of Cuts 1、Smoothness 0.000、Correct UVs オン（02:43）
- 【画面】Scale: X 1.000 / Y 1.204 / Z 1.000（04:12）。側面の参照に合わせて体の厚みを増やす
- 【事実】Loop Cut の Correct UVs をオンにすると、既存の UV を崩さずに辺を足せる
- EP1 との差: EP1 は立方体から胴体を作り、首を押し出した。本動画は逆に首から下へ伸ばす

## 3. 背中・お尻・腕の穴（04:35〜06:53）

- 【画面】04:35 で肩から背中、お尻までの形ができている。肩の先は短く切れた状態
- 【画面】Bevel: Affect Edges、Width Type Offset、Segments 1、Loop Slide オン（05:17）。胴の辺を 2 本に分けて密度を上げる（部位は要確認）
- 【画面】06:27 の右面ビューで、肩の横に腕を付けるための丸い穴がある
- 【画面】Move の値は Y 0.040574 m など数 cm 単位（06:27、06:53）

## 4. 胸と肩のトポロジー（07:36〜11:49）

- 【画面】Knife Topology Tool、ツール設定の Occlude Geometry オン（07:36、09:13、16:22）
- 【事実】Occlude Geometry がオンだと、手前に見えている面だけを切る
- 【画面】Sculpt Mode、Grab、Radius 127 px、Strength 0.400 で胸板を整える（08:03）
- 【画面】11:22 の正面で、胸の下の線と腹筋の区切りが辺の流れとして入っている
- 【画面】首から肩にかけて一部の辺が赤く表示される（07:36 など）。UV のシームと思われる（要確認）
- 【話者】トポロジーをどんな形にしたいか、いろいろ試している（12:29 の画面テロップ）

## 5. 脚とお尻（08:33〜15:44）

- 【画面】08:33、14:29 でお尻から太ももへ辺が回り込む構成を作り直している
- 【画面】ひざは Knife で辺を足して関節の形を作る（09:13）
- 【画面】09:13 以降、Mirror の下に Subdivision Surface（Catmull-Clark）が追加されている
- 【画面】Sculpt Mode の Grab で腰と脚の輪郭を整える。Radius 90 px（13:52）、59 px（17:42）、Strength はいずれも 0.400
- 【画面】15:44 は衣装の参照（ズボンのベルト位置）に腰の高さを合わせている様子（要確認）

## 6. 腕（13:08〜16:22）

- 【画面】13:08 で腕が肩から伸びた状態。腕の頂点を Scale 0.963（XYZ 同値）で縮めて太さを調整
- 【画面】16:22 の正面で、腕は水平よりやや下げた向き（角度の数値は画面になし、要確認）
- 【画面】腕にも一定間隔でループが入っている。ひじの辺の密度は画面からは判断できない（要確認）

## 7. 手（18:18〜21:40）

- 【画面】18:18 以降は画面が左右 2 分割の早回し
- 【画面】手は体と別のオブジェクト Circle.003。名前から円（Circle）を元にした円柱で指を作ったと思われる（要確認）
- 【画面】指は先を丸めたカプセル状。Scale 0.925（XYZ 同値）で大きさをそろえる（18:18）
- 【画面】Merge: Type At Center（18:46）。指の根元の頂点をまとめる
- 【画面】親指は手のひらの側面から伸ばす（20:09）
- 【画面】Grid Fill: Span 3、Offset 0（21:13）。指と手のひらの間の穴を埋める
- 【画面】Circle.003 のモディファイアーに Subdivision Surface（Levels Viewport 1、Render 2、Optimal Display オン）
- 【事実】Grid Fill は、向かい合う 2 本の辺のループ（または 1 本の閉じたループ）の間を四角面の格子で埋める
- 【画面】21:40 は手首まわりの面を調整している（部位は要確認）

## プロポーションの決め方

- 【画面】正面は全身イラストに直接重ねて、肩幅・腰の位置・脚の長さを合わせる
- 【画面】体の厚みは側面の参照を見て Y 方向だけ拡大する（1.204 倍）
- 【画面】右上の小さな 3D ビューで全身を常に表示し、部分の編集中も全体の比率を確認する
- 【話者】男性の体は慣れていないので、辺の流れを試しながら決めた（説明文・テロップ）

## 落とし穴・チェック項目

- 頭と体を 1 つのメッシュにする場合、頭側の Mirror 設定（Clipping）がそのまま体にも効く
- Knife Topology Tool で辺を引き直すときは Occlude Geometry をオンにして、裏側の面を切らない
- 辺を足すときは Loop Cut の Correct UVs をオンにして、先に作った顔の UV を崩さない
- 指は 1 本ずつ作ってから手のひらとつなぐ。つなぎ目の穴は Grid Fill で四角面にする
- ナレーションがない動画なので、画面の値以外の根拠がない。手順の順番は推定を含む
