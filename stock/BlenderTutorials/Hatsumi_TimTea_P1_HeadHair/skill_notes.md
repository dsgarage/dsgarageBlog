# Hatsumi「TimTea P1 Head and Hair」Skill 化用ノート

出典: YouTube「Making A 3D Vtuber Avatar for TimTea! Part ~1 Head and Hair『Blender』」（Hatsumi、2023-07-23 公開、26:20、英語。ナレーションなし）。
凡例: 【話者】= 作者の意見・運用上の判断（説明文と画面テロップのみ）、【事実】= Blender の一般的な仕様、【画面】= 動画の画面で確認した値。画面から推測したものは「(要確認)」。時刻は動画内の時刻。
読み取り範囲: 抽出フレーム 130 枚のうち 30 枚。フレームの間（約 40〜60 秒）の操作は見えていないため、手順の順番は前後のフレームからの推定を含む。

## 前提・環境

- 【画面】Blender のバージョン表示はこの回のフレームでは確認できず（要確認）。第 2 回の画面は 2.93.18
- 【画面】画面左に全ツールの名前つきツールバー、右上にアウトライナー、右下にモディファイアーのプロパティという配置
- 【話者】依頼者から制作過程の記録を頼まれて収録した。頭と髪の基本モデリングと顔のテクスチャを扱う（説明文）
- 【画面】00:30 の画面タイトルは「W1 Day 1: Head Modeling and Texturing」

## 1. 参照画像の置き方（00:30〜）

- 【画面】顔のアップのイラストを正面に、全身の三面図を横向きの板（Plane.003）に貼って配置
- 【画面】正面ビュー（Front Orthographic）で、顔イラストとメッシュを重ねて作業する
- 【事実】参照を板メッシュに貼る方法と、画像エンプティで置く方法がある。どちらを使ったかは、アウトライナーの名前（Plane.003）から板メッシュと思われる（要確認）
- Skill 化するなら: 顔のアップと全身図を分けて置き、顔は正面、全身は作業の邪魔にならない位置に置く

## 2. モディファイアーの初期設定（00:30〜）

- 【画面】Mirror: Axis X、Clipping オン、Merge オン 0.001 m
- 【画面】Subdivision Surface: Catmull-Clark、Levels Viewport 1、Render 2、Optimal Display オン
- 【事実】Clipping をオンにすると中心線上の頂点がミラー面を越えない
- 【事実】Subdivision Surface をモディファイアーのまま残すと、少ない制御頂点で形を編集できる
- EP1 との差: EP1 はサブディビジョンを適用して頂点を増やしてから編集した。本動画はモディファイアーのまま残す

## 3. 顔のトポロジー（01:07〜04:12）

- 【画面】目の穴を囲む輪（アイループ）を最初に作る（01:07）。穴の縁から外側へ面を広げる
- 【画面】01:51 で目と口に穴のある仮面状。口のまわりにも輪がある
- 【画面】02:35 で正面から、参照の目の線（上まぶた・下まぶた）に辺のループを沿わせている
- 【画面】04:12 で顔の下半分が完成。あごはアニメ調に細くとがらせる
- 【画面】鼻は小さい突起程度。鼻先の周囲に輪がある（06:40 のワイヤーで確認）
- Skill 化するなら: 目 → 口 → その間をつなぐ順で輪を作り、輪と輪の間を四角面で埋める

## 4. 頭を閉じる（03:19〜）

- 【画面】03:19 で顔から後頭部まで面を伸ばし、頭を閉じた状態
- 【画面】首は頭の下から円筒状に伸ばしてある（07:21 の画面）

## 5. 目・まつ毛・眉（05:02〜06:40）

- 【画面】まつ毛と二重の線は、目の上に細い帯状の面を重ねて作る（05:02、05:44）
- 【画面】眼球は中心から放射状に辺が伸びる円形のトポロジー（05:44）
- 【画面】眉も細い帯状の面（05:44）
- 【画面】Move 後のオペレーターパネルに Z −0.033195 m などの値。帯を少しずつ動かして位置を合わせている
- 【画面】編集中に一部の辺がピンク（マゼンタ）で表示される。意味は画面からは判断できない（要確認）

## 6. スカルプトで輪郭を整える（07:21〜）

- 【画面】Sculpt Mode、Grab ブラシ、Radius 102 px、Strength 0.400（07:21）
- 【画面】頭の丸み・頭頂の高さを、参照の髪の内側の輪郭に合わせている
- 【画面】08:08 で Cube.003 ができている（Subdivision Surface のみ、Optimal Display オフ）。頭を複製した髪の土台と思われる（要確認）
- Skill 化するなら: 編集モードで頂点を 1 つずつ動かすのは局所の調整、シルエット全体はスカルプトの Grab と使い分ける

## 7. 顔のテクスチャ（09:03〜13:18）

- 【画面】Texture Paint ワークスペース。左に Image Editor（UV 表示）、右に 3D ビュー
- 【画面】09:03 に File の Append 画面。「TimTea Base.blend」「TimTea Base Head.blend」から取り込んでいる（何を取り込んだかは要確認）
- 【画面】画像: 「TimTea Head」「TimTea Head Light.png」「TimTea Head Shadow.png」の 3 枚
- 【画面】マテリアルの Surface は Mix。Color2 に「TimTea Head Shadow」の画像、Fac 0.000（09:03）
- 【画面】ブラシ: Smear、Radius 62 px、Strength 0.274（09:56）。10:45 は Radius 29 px
- 【画面】マテリアル一覧に「OH_Outline_Material」がある（10:45 以降）。輪郭線用のマテリアルと思われる（要確認）
- 【画面】11:34 のステータスバーに「Saved image "D:\TimTea 3D model\tex\TimTea Head.png"」
- 【画面】12:22 の編集モードで、目の穴・口・首の境目に赤い辺。UV のシームと思われる（要確認）
- 【画面】描いた要素: 眉、まぶたの線、頬の赤み、鼻の線、口
- 【事実】Texture Paint では、UV を持つメッシュに対して、3D ビューと Image Editor のどちらからでも描ける
- Skill 化するなら: 明部と暗部を別画像にし、マテリアル側で Mix する構成を最初に作ってから描く

## 8. 髪のモデリング（14:12〜19:03）

- 【画面】髪は束ごとに別オブジェクト（Cube.003〜Cube.010）
- 【画面】髪の Mirror: Axis X、Mirror Object に Cube.002（頭）。Clipping はオンとオフの両方の束がある
- 【事実】Mirror Object を指定すると、そのオブジェクトの原点を中心に対称化される
- 【画面】束を Scale で Y だけ 0.435（14:12）、0.700（15:10）に縮めて薄くする
- 【画面】前髪の調整: プロポーショナル編集 Smooth、Size 0.424、Connected オン（16:59）。22:13 は Size 0.180
- 【事実】Connected をオンにすると、つながった頂点だけに影響が及ぶ。隣の束が動かない
- 【画面】後ろ髪: 頭を一周する帯から下向きに束を並べる（19:03 の右面ビュー）
- 【画面】アウトライナーに NurbsPath・BezierCircle・NurbsPath.001〜.003 もあるが、非表示のものが多い。カーブで髪を作る方法も試したかは不明（要確認）

## 9. 髪の仕上げ（20:15〜24:52）

- 【画面】Sculpt Mode、Grab、Radius 129 px、Strength 0.400 で束の流れを参照に合わせる（20:15、23:06）
- 【画面】アホ毛は Cube.010 として別に作り、Subdivision Surface のみ（23:57）
- 【画面】アホ毛の角度はプロポーショナル編集 Size 1.464 で大きく動かす
- 【画面】24:52 でも束ごとに頂点を調整している。一部の辺がピンク表示（意味は要確認）

## プロポーションの決め方

- 【画面】頭の大きさ・目の位置・あごの形は、正面の顔イラストに直接重ねて合わせる
- 【画面】頭頂の高さは、参照の髪の内側に収まるようスカルプトで調整
- 【画面】髪のボリュームは参照の髪の外形線まで。前髪の束は目にかかる位置まで下ろす

## 落とし穴・チェック項目

- 髪を別オブジェクトにした場合、Mirror Object を頭に指定しないと対称の中心がずれる
- 束を動かすときは Connected をオンにして、隣の束の巻き込みを防ぐ
- まつ毛・眉を帯状の面にするなら、顔の面から少し浮かせて重ねる
- テクスチャを描く前に、目と口の縁にシームを入れて UV を切り開く
- ナレーションがない動画なので、画面の値以外の根拠がない。手順の順番は推定を含む
