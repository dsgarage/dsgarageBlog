# Hatsumi「TimTea Part 3 Clothing」Skill 化用ノート

出典: YouTube「Making A 3D Vtuber Avatar for TimTea! Part ~3/ Clothing『Blender』」（Hatsumi、2023-08-10 公開、28:59、ナレーションなし）。
凡例: 【話者】= 作者の意見・運用上の判断、【事実】= Blender の一般的な仕様、【画面】= 動画の画面で確認した値・操作。画面から推測したものや判別できないものは「(要確認)」。時刻は動画内の時刻。
注意: この動画は BGM のみでナレーションがない。whisper と YouTube 字幕に意味のある発話はなく、【話者】の項目は説明文由来の 1 件だけ。手順はすべて【画面】からの読み取り。確認したフレームは 30 枚で、フレーム間の操作は推測を含む。

## 前提・環境

- 【話者】服の制作は合計約 10 時間。動画は 2 本に分ける（説明文）
- 【画面】Blender のバージョンはステータスバーが切れていて読めない（要確認）
- 【画面】画面左上と横に、依頼者の設定画（正面・背面・顔アップ）を画像エンプティで常時表示。Empty〜Empty.005 が references コレクションにある
- 【画面】コレクション構成: references / hair / Body（素体と複製）/ Clothing（服）

## 1. 素体を複製して服の土台にする（00:46〜02:28）

- 【画面】Body コレクションに base original / base re / base re.001 が並ぶ（01:37）。base re が作業用の素体、base re.001 がその複製
- 【画面】02:28 には base re.001 が Clothing コレクションへ移動している
- 【画面】複製には素体のモディファイアーがそのまま残る: Mirror（Axis X、Clipping オン、Merge オン 0.001 m）→ Subdivision Surface（Catmull-Clark、Levels Viewport 1、Render 2、Optimal Display オン）
- 【画面】00:46 は首元の辺ループを選び、襟ぐりの位置に移動している
- 【画面】02:28 は Right Orthographic で頂点を移動。Move パネルの値は X 0.0099 m / Y 0.0004 m / Z 0.0033 m 程度で、体からわずかに浮かせる規模の調整
- 【事実】複製（Shift+D）→ 右クリックでキャンセルすると同位置に複製が残る。M でコレクションへ移動
- Skill 化の手順案: 素体を複製 → 服ごとに名前を付けて Clothing へ → 服にならない部分（頭・手足先など）の面を削除 → 開口部の辺ループを整える → 法線方向にわずかに膨らませる（体との距離を確保）→ スカルプトでゆとりを出す（削除と膨らませ方の操作自体はフレームに映っていない、要確認）
- 【事実】法線方向に一様に膨らませるには Shrink/Fatten（Alt+S）が使える。左ツールバーに Shrink/Fatten が表示されている（使用場面は未確認）

## 2. パーツ分けとオブジェクト名

- 【画面】07:02 時点の Clothing: jacket inner / jacket outer / shirt
- 【画面】P4 の完成時点（参考）: belt jacket / belt sleeve / belts / choker / gloves blue / gloves outer / hoodie / jacket inner / jacket outer / jacket pockets / pants / shirt / jacket buttons / laces / laces jacket / laces things / shoe holes / shoes / x pants / zipper
- 【画面】上着は内側（inner）と外側（outer）で別オブジェクト。フードは jacket inner.001 / .002 / .003 と複製を重ねて作っている
- Skill 化の指針: 重なる層ごと・部品ごとに別オブジェクトにして名前を付ける。貫通の修正や表示切り替えがしやすい

## 3. スカルプトでの形出し・シワ・ゆとり

- 【画面】パーカーのポケット縁: Smooth ブラシ Radius 64 px / Strength 0.493（03:20）
- 【画面】ジャケット（base re.003）の身ごろと袖: Grab ブラシ Radius 95〜98 px / Strength 0.400（04:18〜06:03）
- 【画面】パンツ: Grab Radius 98 px / Strength 0.400（09:14）、Clay ブラシ Radius 142 px / Strength 0.500（11:29）
- 【画面】フード: Grab Radius 179 px / Strength 0.400（15:16）
- 【画面】首元のパーツ base re.005: Grab Radius 155 px / Strength 0.400（22:32）
- 【画面】袖はふくらみのある形（パフ気味）で、袖口に向かってすぼまる。細かい布のシワは彫っていない。シワより大きなシルエットのゆとりを優先している
- 【画面】袖の一部（肩下の切り替え）に明るい色のマテリアルを割り当て、設定画の配色境界を確認（06:03、Material.004）
- 【事実】Grab ブラシは頂点数を変えずに形だけ動かすので、Mirror・Subdivision を付けたままでもトポロジーが崩れにくい

## 4. 厚み（ソリッド化）と布端

- 【画面】モディファイアー一覧に Solidify は確認できない（確認フレームの範囲では Mirror と Subdivision のみ）
- 【画面】袖口（jacket inner.001、13:27）は布の端が内側に折り返された断面になっている。端の辺ループを押し出して内側へ戻したものと推測（要確認）
- 【画面】フードの縁の辺ループを選び Move（X 0.0355 m / Z 0.0355 m）で調整（14:28）
- 【画面】袖に沿った細い帯状のパーツ（27:28、shirt.002）は、辺を選んで押し出した細い帯。設定画の袖ラインを立体で表現していると推測（要確認）
- 【画面】shirt のすそを Extrude Region and Move（Move X 0.1358 m / Z -0.2695 m）で伸ばしている（23:50）
- Skill 化の指針: 見える布端だけ折り返しで厚みを作る方式と、Solidify を使う方式を選択肢として並べる。この動画は前者と見られる（要確認）

## 5. スカート・フリル

- 【画面】この回の衣装（パーカー・ジャケット・パンツ）にはスカートやフリルがなく、該当する工程はない

## 6. 手袋（手からの作成）

- 【画面】base re.003 の手の頂点を選択し、Resize 1.012（X/Y/Z 同値）、Proportional Editing オン、Falloff Smooth、Proportional Size 0.029、Connected オン（18:26）
- 【画面】手の甲側の辺を選び直し、甲の開口部（指先の出るデザインの切り替え）を整える（19:14）
- 【画面】手首まわりは base re.004 として別に作成（P4 の 14:34 では base re.004 が手の甲まで含む手袋として映る。分担は要確認）。前腕のループを Move Y 0.008 m で調整（19:56）
- 【画面】P4 の 14:34 では gloves の手の甲に紫、手首に緑の色分けが見える（パーツ範囲の確認用と推測、要確認）
- Skill 化の手順案: 手のメッシュを複製 → 手袋にする範囲だけ残す → 1.01 倍前後に拡大（プロポーショナル編集で縁をなじませる）→ 開口部の辺を整える

## 7. ひも・ファスナー・小物

- 【画面】パーカーのひも: laces jacket。首元から左右 2 本、先端に結び目状のふくらみ。モディファイアーは Subdivision（上）→ Mirror（下）、Mirror の Clipping オフ（16:12〜16:57）
- 【事実】中央線をまたがない独立部品は、Clipping をオンにすると頂点が中央に吸着して動かしにくくなる
- 【画面】ファスナー: zipper。Subdivision のみ（Mirror なし）。歯をチェーン状に並べている。Move Y 0.308 m、Proportional Size 0.029（20:46）
- 【画面】Circle というオブジェクトもある（用途は未確認）
- 【画面】ひし形の枠状パーツを shirt 内で編集（25:06）。ひもの先端金具かファスナーの引き手と推測（要確認）
- 【画面】パンツ（pants.001 と読める、要確認）にベルトループと、そこから下がるストラップ（Subdivision のみ）（28:36）

## 8. パネルラインとトポロジー整理

- 【画面】Knife Topology Tool 使用時、ヘッダーに Occlude Geometry と Only Selected のチェックが見える（21:35、jacket inner.003）
- 【画面】Dissolve Edges（Dissolve Vertices オン、Face Split オフ）で辺を減らす（17:42）
- 【事実】Knife の Occlude Geometry をオフにすると、裏側の面まで貫通して切れる。オンなら手前の面だけ
- Skill 化の指針: 設定画の色の切り替え位置に辺を通しておくと、あとで UV やマテリアル分けがしやすい

## 貫通対策（画面から読み取れた範囲）

- 【画面】服はすべて素体の複製なので、辺の流れが体と一致する。リグのウェイト転送で服と体が同じように変形しやすい構成（ウェイト工程はこの回に映っていない、要確認）
- 【画面】手袋は 1.012 倍、服の調整はミリ単位の移動で、体との隙間を小さく保つ
- 【画面】服の下の体（base re）は作業中も表示されている。服を着せた状態で見比べながら調整している
- 【事実】服の下に隠れる体の面を削除するか、マスク用の頂点グループで隠すと、ポーズ時の貫通が見えにくくなる（この動画では未確認）

## 落とし穴・チェック項目

- 複製した服に素体の Mirror・Subdivision が残っていることを確認する。中央の 1 本部品（ファスナー）は Mirror を外す
- 独立部品（ひも）は Mirror の Clipping をオフにする
- 服は層（inner / outer）と部品ごとに別オブジェクト・名前付きにする
- 体からの距離はミリ単位。膨らませすぎると体型が変わって見える
- 布の厚みをどう付けるか（折り返しか Solidify か）を最初に決める
