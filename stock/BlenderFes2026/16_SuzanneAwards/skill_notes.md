# D2 S8 skill_notes：CG コンテスト講評から抽出した評価基準

> 出典: Blender Fes 2026 AW Day2「b3d創作祭「スザンヌ」 結果発表&講評セッション」（2026-09-27、本編 18:45〜19:29）。
> すべて**審査員個人の意見**であり、コンテストの公式審査基準ではない。作品名・作者名は配信スライドの表記に従う。
> 区分: 【話者】発言した審査員 /【事実】講評で語られた内容の要約 /【画面】スライドで確認できた情報。聞き取りが不確かな箇所は「(要確認)」。
> 題材はお題「スザンヌ」固有の話を含むため、汎用化できる形に言い換えた見出しを付けている。

## A. 評価される作品の条件

### A1. お題の「共通前提」を使い、表現方法でずらす
- 【話者】涌井嶺
- 【事実】応募作の多くは「スザンヌ＝ユーザーが日常的に使うテスト用モデル」という前提を共有していた。その中で表現方法が面白い作品を選んだ
- 【画面】涌井嶺賞「今日もそばにいる」（深澤真紀子さん）
- Skill 化: お題の一般的なイメージを洗い出し、同じ前提から「舞台」「感情」「視点」のどれを変えるかを決める

### A2. 特定の観客に向けた内輪ネタでも、作品として完結させる
- 【話者】3D人 / 高原さと / 龍村某
- 【事実】Blender ユーザーにしか通じないネタに振り切りながら、作品としてのまとまりがあることが評価された。10 名中 5 名が同じ作品（松尾豪さん「Blender総合病院 午前1時34分」）を選んだ
- 【画面】3D人賞・横原大和賞・龍村某賞のスライドで同作品を確認。高原さと賞・東條あずさ賞は講評音声のみで確認（スライド未確認）

### A3. 何度も見返したくなる情報密度（小道具・掲示物）
- 【話者】3D人 / FUKUPOLY / 横原大和 / 東條あずさ / 龍村某 / 萩原亮
- 【事実】掲示板の張り紙、受付画面の UI、チラシの文面、壁のカレンダーの印（募集期間）など、細部の小ネタが多くの審査員から挙げられた
- Skill 化: 主題を説明する小道具を画面の複数箇所に配置し、2 回目以降の鑑賞で発見がある構成にする

### A4. 感情に直接訴える
- 【話者】ますく
- 【事実】技術力やストーリーではなく「理屈抜きに可愛い、欲しい」と思わせたことを最優秀の理由とした
- 【画面】ますく3D賞「スザンヌいぐるみ」（徳永虎次朗さん）

### A5. 審査の観点を明示した例（独自解釈・造形の説得力・世界観）
- 【話者】萩原亮
- 【事実】テーマへの独自の解釈、造形的な説得力、世界観の構築の 3 観点で評価した
- 【話者】龍村某
- 【事実】お題の性質上、技術より発想の面白さを基準にした
- Skill 化: 応募前のセルフチェック項目として「解釈」「造形」「世界観」「発想」を独立に採点する

### A6. 身近な場所と組み合わせて現実味を出す
- 【話者】東條あずさ
- 【事実】「実験台のスザンヌ」を病院という身近な場所と組み合わせたことで妙なリアルさが出た。患者ごとに違う服の付き添いがいることで現実味が増した

### A7. 見る人に「この後」を想像させる余白
- 【話者】3D人 / 龍村某 / CGWORLD 編集部
- 【事実】「この後どうなるのか」と想像が膨らむ終わり方が評価された。「The Awakening」では、最後に暗闇で赤く光る目が次の展開を予感させる点が挙げられた
- 【画面】CGWORLD 賞「The Awakening」（musha さん）

### A8. テーマ性が技術デモを物語に変える
- 【話者】CGWORLD 編集部
- 【事実】「道具として扱われた存在がもし同志だったら」というテーマが、シミュレーションの実験風景を物語に変えていると評価された

### A9. 学んだテクニックを自分の表現に取り込む
- 【話者】ますく
- 【事実】過去の Blender Fes で紹介された表現（ノードがメタ的に登場するアニメーション、Blender の UI が動くアイデアなど）が応募作に生かされていたことを好意的に評価した

### A10. 要素が少なくても成立する作品
- 【話者】東條あずさ
- 【事実】音声・カメラ・アニメーションがそろった作品を選びがちだったが、シンプルな 2D 作品「解せぬ。」（わんころさん）の味わいを挙げた

### A11. 人の手で作られた作品の魅力
- 【話者】横原大和
- 【事実】AI で乱雑に生成された動画や画像よりも、人の手で作られた愛のある作品には何度見ても飽きない魅力がある、と述べた

## B. よくある失敗・惜しかった点

### B1. 主役がお題のモチーフになっていない
- 【話者】涌井嶺 / 3D人
- 【事実】「土曜19時30分」（大西後東さん）は映像の質を高く評価されつつ、スザンヌが脇役的だった点で 1 位を逃した（涌井嶺）
- Skill 化: 完成前に「お題のモチーフを取り除いても作品が成立するか」を確認する。成立するなら主役になっていない

### B2. 「なぜそのモチーフなのか」の説明が弱い
- 【話者】FUKUPOLY
- 【事実】「SUZANNE×3 : RITUAL」（Shosuke Watanabe さん）は完成度が高いが、なぜスザンヌなのかの物語がもう少しあると深みが増した

### B3. 小道具の意味付けで説得力を取り逃がす
- 【話者】東條あずさ
- 【事実】「アルバイト急募！」のスザンヌが持っている紙が手順書や注意事項なら、「現場」としての説得力がもう一段上がった

### B4. モチーフの特徴（動物らしさ）を活かしきれていない
- 【話者】FUKUPOLY
- 【事実】「アルバイト急募！」に対し、尻尾や猫背・前かがみの姿勢を加えると猿らしさや愛嬌が出たかもしれないと助言。ただし人間的な体つきによる不気味さも魅力になっていると補足

### B5. 発想がほかの応募作と重なる
- 【話者】ますく / 3D人
- 【事実】「スザンヌを工場で製造する」「実験台にされ続けるスザンヌ」は複数の応募があった。その中で製造工程のリアルさや、ダークな仕上げで差が付いた
- Skill 化: お題の定番ネタを事前に列挙し、同じネタを選ぶなら描写の解像度か感情の方向で差別化する

## C. Blender の技術面の指摘

### C1. モデリング
- 【話者】涌井嶺 【事実】サブディビジョンなしの角張った形でも、ポーズと周囲との関係で「柔らかそう」に見せられる
- 【話者】萩原亮 【事実】デフォルメされた形状の中に金属骨格を納め、構造の説得力を保つのは難しい（「Hasta La Vista Monkey!」Odie Burger さん）
- 【話者】萩原亮 【事実】顔だけの存在でも「動き回りそう」と感じさせる造形と表情が説得力を生む（「SUZAHARA」Irio さん）
- 【話者】日本モンキーセンター 【事実】チンパンジーのような動物の造形が、霊長類の専門家から見ても違和感がないと評価された（「邂逅」さいとうさん）

### C2. 質感
- 【話者】萩原亮 【事実】皮膚と金属という異素材の描き分け、血管のディテール（「Hasta La Vista Monkey!」）
- 【話者】高原さと 【事実】ディテールの多い部分と、つるりとしたセルルックの本体のメリハリがきれいなバランスになっている（「Assembly line」石井貴大さん）
- 【話者】萩原亮 【事実】フォトリアルは再現度に目が行きがちだが、画面全体の緊張感で引き込むことが重要（「邂逅」）
- 【話者】ますく 【事実】温かいライティングとレンダリングが、ぬいぐるみの柔らかさを引き立てている（「スザンヌいぐるみ」）

### C3. ライティング・配色
- 【話者】萩原亮 【事実】画面中央の逆光や炎による明度差で、シルエットの人物に視線を集める（「SUZAHARA」）
- 【話者】日本モンキーセンター / 萩原亮 【事実】暗い画面で顔にだけ光を当て「見られている」感覚を強める。高彩度の仮面を 1 点だけ置いて視線を集める（「邂逅」）
- 【画面】「邂逅」の作者コメントに、キアロスクーロ（明暗の強い対比）を意識したライティングとある
- 【話者】FUKUPOLY 【事実】黒を基調にオレンジと黄色を効かせる配色（「アルバイト急募！」）。ネオンカラーと深い闇のコントラスト（「SUZANNE×3 : RITUAL」）

### C4. 構図・画面構成
- 【話者】FUKUPOLY 【事実】視線を自然に中央へ導く構図（「アルバイト急募！」）
- 【話者】ますく 【事実】広角で現場全体を見せつつ、手前に飛び出す要素を置いて奥行きとダイナミックさを出す。キャラクター配置と光で視線を誘導する（「アルバイト急募！」）
- 【話者】高原さと 【事実】左に全体、右に細部のアップを並べて切り替える見せ方（「Assembly line」）
- 【話者】東條あずさ 【事実】アイデアを 1 枚の中で整理して収める絵作り（「SUZAHARA」）
- 【話者】横原大和 【事実】囲んでこちらを見つめる配置が映画的（「邂逅」）

### C5. アニメーション・映像演出
- 【話者】高原さと 【事実】冒頭カットを映像の導入として成立させる。要素が流れてくるタイミングで笑いを作る（「Blender総合病院 午前1時34分」）
- 【話者】高原さと 【事実】少ない要素でも、走るときのカメラの揺れ、画面のノイズ感、ライティングで映像として見せられる（「Run Away」北野凌太郎さん）
- 【話者】3D人 【事実】規則的な動きや繰り返しには CG ならではの気持ちよさがある（「Assembly line」）
- 【話者】東條あずさ 【事実】アニメーション・カメラ・エフェクト・リズム感・色がそろうと、何度もループして見たくなる（「SUZANNE×3 : RITUAL」）
- 【画面】「SUZANNE×3 : RITUAL」の作者コメントに、演出効果もほぼすべて Blender で制作したとある
- 【話者】萩原亮 【事実】モーションブラーによる動的な演出（「SUZAHARA」）
- 【話者】涌井嶺 【事実】特撮らしさはコンポジットで表現する必要があり、その映像表現の質が高い（「土曜19時30分」）
- 【話者】CGWORLD 編集部 【事実】セルフラクチャーなどのシミュレーションを研究施設風の演出でテンポよく見せる構成（「The Awakening」）
- 【話者】日本モンキーセンター 【事実】ゴリラのドラミングは手を開いた形が正しい。拳で描かれがちな動作を正確に描いた点を評価（「SUZANNE×3 : RITUAL」）
- Skill 化: 動物の動作は、図鑑や動物園の映像などの一次資料で手の形や姿勢を確認してから付ける
