# S5「フォトリアルCGテクニック」Skill 化用ノート

出典: Blender Fes 2026 AW Day2「フォトリアルCGテクニック」（イオリ、2026-09-27 15:00–16:00。本編は 15:00:05〜15:47:15）。
凡例: 【話者】= 講演者の意見・運用上の判断、【事実】= Blender の一般的な仕様、【画面】= 配信画面で確認した値。聞き取りや読み取りが不確かなものは「(要確認)」。
講演で扱われなかった項目は「講演では扱われず」と明記し、一般的な仕様だけを【事実】で補う。

## 前提・環境

- 【画面】Blender 5.2.0 LTS（タイトルバーで確認）。レンダーエンジンは Cycles、デバイスは GPU 演算
- 【画面】HDRI の適用に Poly Haven のアドオンを使用（講演では「Holyheaven」と聞こえた。名称は要確認）。アセットブラウザーからドラッグ＆ドロップで適用し、ワールドのパネルに「Strength (EVs)」「Warmth」「チント」の項目が出ている
- 【話者】写真素材は textures.com の画像と自分で撮影した写真を併用。自分で撮った写真でも同じ手順で使える

## 基本原理: 写真から「色・質感・ディテール」を借りる

- 【話者】フォトリアルへの最短経路は写真の活用。写真には色、経年劣化の質感、現実のディテールがすでに入っており、CG の工程を丸ごと省ける
- 【話者】写真の使い方は 2 段階。(1) 平面として読み込んでそのまま使う、(2) 写真をリファレンス兼テクスチャとしてモデリングする
- 【話者】写真はベースカラー専用ではない。明暗を粗さ・バンプ・係数（マスク）にも使える。スライドの要約は「色を借りるだけでなく、欲しい質感だけを借りられる」
- 【話者】写真の素材と使う先の素材は違ってよい（金属の汚れ写真をガラスの曇りに使う）

## 写真の活用 1: そのまま使う

- 平らな壁: 画像を平面メッシュとして読み込むだけで成立する場合がある
- 遠景: 写真 1 枚を少し湾曲させて置く
  - 【話者】遠くほど建物同士の高さや大きさの差がなくなるので、遠景は写真 1 枚でもリアルに見えやすい
  - 【話者】建物と地面の境にループカットを入れ、地面を手前に少し伸ばすと若干立体的になりなじむ
  - 背景になじませる手順: 明度をカラーランプで調整して空を透過 → 彩度を調整 → 背景 HDRI の空の色をオーバーレイで薄く重ねる
  - 【画面】ミックスノード: カラー、ブレンドモード「オーバーレイ」、係数 0.323、「係数を制限」オン
- 植物・小物: 背景を透過した画像を平面に貼る
  - 【話者】斜めの角度に弱いときは、ループカットを入れてプロポーショナル編集で一部を前へ押し出す

## 写真の活用 2: 写真に合わせてモデリング

### 共通手順
- 写真を平面で読み込み → 対象部分をループカットで囲って切り出す → 複製して不要部分を削除 → 原点付近に移動
- UV エディターで、正面の画像が平面に収まるよう頂点を調整 → 面を押し出して大まかな形 → 写真の凹凸に合わせて辺を足し押し出す
- 【事実】辺スライドは G を 2 回押す。既存の辺を使えるときは辺を追加せずスライドで合わせる
- 【事実】ツール設定のオプションにある「Correct Face Attributes」（日本語 UI では「面の属性を補正」と見られる。要確認）を有効にすると、頂点移動や面の拡大縮小で UV が伸びない
- 【話者】ループカットで余計な面を増やしたくない部分は、新しい立方体を追加して作る
- 【話者】曲線的な部分はナイフツール（K）。先にナイフを使うとループカットが入りにくくなるので、なるべく最後に使う
- 【事実】奥へ行くほど小さくなる円形部分は、ピボットポイントを「個々の原点」にしてスケール（講演では「キーボットポイント」と聞こえた）

### 自動販売機の商品棚
- 3D カーソルを Shift+S で選択物へ → プリミティブを追加（種類は要確認）→ 縮小してベベルで大まかな形
- 【話者】写真を使う場合はこの程度のディテールで十分
- 【話者】複製時は軸を固定せず、目分量で回転・スケールしてランダムさを出す
- 【話者】作ったものはリンク選択でまとめて選ぶ（講演者はリンク選択を独自のショートカットに割り当て）
- 正面ビュー → U →「ビューから投影」→ 写真の商品に合わせる
- 伸びる面は選択して「キューブ投影」で展開し、写真の何も写っていない白い領域へ寄せる。見えない面は省略してよい
- 透明な板: 枠を 1 周選択 → Shift+D で複製 → F で面張り → 余分な頂点は「限定的溶解」で削除 → 押し出して厚み → グラス BSDF
- 【事実】表示がおかしいときは法線の問題。Shift+N で法線を再計算
- 【画面】グラス BSDF: マルチスキャッタ GGX、IOR 1.500（粗さは 0.500 と見えるが要確認）
- 【画面】照明はエリアライト（正方形、サイズ 1 m、広がり 180°）。パワーは読み取れず（要確認）

### 家（形が先、テクスチャが後）
- 大まかな形を先に作る → マテリアルを作成し、Node Wrangler の Ctrl+T で画像テクスチャを追加して家の写真を読み込む
- 全体の UV をいったん写真のディテールのない領域に置く
- 側面を選び、撮影位置に近い画角にビューを合わせて「ビューから投影」→ UV の角度合わせの手間が減る
- ゆがみが残る所は辺を追加し、窓や扉の位置に UV を合わせる。中央に辺を入れると位置を合わせやすい
- 【話者】同じ場所から取れない質感は、反対側など別の場所から同じ質感を取ってよい
- 【話者】写っていない床や柵は、壁の別領域や、錆びた金属の別写真で補う（解像度を上げたい場合も別写真）
- 【画面】家の外壁: プリンシプル BSDF、ベースカラーに写真、粗さ 0.500、IOR 1.500

### 撮影時の心得
- 【話者】窓などのディテールがない汎用的な壁の領域を広めに写しておく。これがないと写っていない面を同じ質感で作れない

## モデリング: 均一さを崩す

- 【話者】CG らしさの主因は、平行・垂直などの均一すぎる要素。現実の直線はわずかにゆがみ、へこんでいる
- 伸ばす・押し出すときに X/Y/Z の軸を固定せず、目分量で少しずらす
- 複製した部品同士にも、違う回転や位置のずれを加える（2 つが完全に同じでないこともノイズになる）
- ベベルで角を削る。【話者】ベベルだけで見栄えが大きく変わる
- 【事実】ナイフツール使用中に C で「Cut Through」（隠れた面まで貫通して切る）。公式マニュアルで C キーと確認済み
- 【話者】「上から物が落ちてへこんだ」など経緯を想像しながらゆがみを入れる。へこみにもベベルを入れると滑らかにつながる

## マテリアル（粗さ・IOR・SSS・ディスプレイスメント）

- 粗さ: 写真の明暗を粗さにつなぐと、暗いところほどつるつる、明るいところほど粗くなる。間にカラーランプを挟んで効き方を調整
  - 【画面】壁の写真 TCom_PlasterDirty0070_1_seamless_L（色空間 sRGB）→ カラーランプ（位置 0.145）→ 粗さ
  - 【話者】黒を真っ黒のままにせず、少し持ち上げて「完全につるつる」を避ける
  - ガラス: グラス BSDF の粗さに金属の汚れ写真をつなぐと曇りのムラになる
- IOR: 【画面】グラス BSDF、プリンシプル BSDF とも 1.500（既定値）。講演で IOR の調整には触れず
- 凹凸: 写真をバンプノードの高さにつなぎ、ノーマルへ。【事実】バンプノードはシェーダーエディターのディスプレイスメントのカテゴリにある
- ディスプレイスメント（実際の変位）: 講演では扱われず。【事実】マテリアル設定のディスプレイスメント方式は既定で「バンプのみ」。実際に形を変えるには「ディスプレイスメントのみ」または「ディスプレイスメントとバンプ」を選び、十分な細分化が必要（Cycles）
- SSS: 講演では扱われず。【事実】プリンシプル BSDF のサブサーフェスのウェイトで設定する
- 【画面】15:01 頃の地下道シーンでボリューム散乱（Henyey-Greenstein、密度 0.001）を持つマテリアルが見える。空気感用と見られるが講演では説明なし(要確認)

### 複数の写真を重ねる（UV を分ける）
- オブジェクトデータプロパティ > UV マップで「+」→ 追加した UV を「Graffiti」と命名
- UV マップノードで Graffiti を選び、グラフィティ画像のベクトルへ
- 壁写真とグラフィティをミックスノードでまとめてベースカラーへ。係数に画像のアルファ（透過部分は 0、描画部分は 1）
- 【事実】画像テクスチャの拡張を「クリップ」にすると繰り返しが消える（講演の「リップ」はクリップと判断。要確認）
- 編集モードで UV マップ Graffiti を選び、位置と大きさを自由に調整
- 【話者】濃すぎればカラーランプで係数を弱める。【画面】ミックスのブレンドモードは「乗算」

### 環境に合わせた汚れ（AO マスク）
- アンビエントオクルージョンノードの出力 → カラーランプ → ミックスの係数。A に元の壁、B に汚れた壁のテクスチャ
- 【画面】AO ノード: サンプル数 16、距離 1.000
- 【話者】AO は物の境目や光が入りにくい所、つまり汚れがたまりやすい所を出す。周りに物を追加すると汚れも追従する
- 【事実】アンビエントオクルージョンノードは Cycles で設計どおりに動作する。EEVEE での挙動は版により異なる(要確認)

## ライティング（HDRI・3 点照明・露出）

- 【話者】基本は HDRI で素早く作る
  1. よく使う HDRI を事前に複数ダウンロードし、すぐ試せる状態にしておく
  2. 朝方・夕方の HDRI を使う。空気感が出しやすく、影が長く伸びて立体感・ダイナミックさが出る
  3. HDRI を決めたら回転させて良い向きを探す
- 【話者】向きの目安は、地面に落ちた影が壁にもつながる位置。影が面をまたぐと立体として強く認識される
- 【画面】HDRI は oberer_kuhberg（1K）、回転 -30.100、Strength (EVs) 0.000
- 画面外の影（ゴボ的な使い方）
  - 大きな板: 平面を追加して拡大し、手前に影が落ちる位置へ。【話者】撮影位置の背後にも何かあると感じさせ、壮大な印象になる。最も簡単で効果が大きい
  - 空を透過した風景写真: アルファに画像をつなぎ、カラーランプで透過範囲を調整、補間を「一定」にしてくっきり抜く → 大きくして影が落ちる位置へ
  - 【話者】画面に映らないので切り抜きは大まかでよい。木や橋などシルエットが面白い透過画像なら何でも使える
- 3 点照明: 講演では扱われず。講演者は HDRI ＋画面外の遮蔽物で光を整える方針
- 露出: 【画面】カラーマネジメントの露出 0.000。仕上げの露出はコンポジットで調整（下記）

## カメラ（焦点距離・被写界深度・センサー）

- 講演では扱われず。カメラ設定の画面も確認できなかった
- 【事実】既定値は焦点距離 50 mm、センサーサイズ 36 mm。被写界深度はカメラのプロパティ > 被写界深度で有効化し、焦点距離（ピント位置）と F 値で調整する
- 【画面】地下道のシーンは縦長の構図（レンダー解像度は読み取れず）

## レンダー設定（Cycles・デノイズ・カラーマネジメント）

- 【画面】遠景シーン（15:02 頃）: ビューポート ノイズしきい値 0.1000／最大サンプル数 1024、レンダー ノイズしきい値 0.1000／最大サンプル数 64／最小 0／時間制限 0 s、デノイズ オン
- 【画面】自動販売機シーン（15:08 頃）: レンダー ノイズしきい値 0.0100／最大サンプル数 4096、デノイズ オン（既定値のまま）
- 【画面】カラーマネジメント: 表示 sRGB、ビュー AgX、ルック なし、露出 0.000
- 【事実】AgX は Blender 4.0 以降の既定のビュー変換。Filmic も選択可能だが、講演では AgX のまま使用
- 【話者】レンダー設定そのものの解説はなし。確認できた値からは、遠景シーンでは低サンプル＋デノイズで速度を優先していたと読める(推測)

## コンポジット

- 【話者】Blender 標準のノードで基本的な加工は十分。よく使う 6 つ: 露出、ビネット、色収差、グレア、ノイズ、シャープ
- 【話者】最近の Blender で追加されたノードのセットを中心に使う（アセットとして提供されるノードグループと見られる。要確認）
- 【画面】5.x のコンポジターはノードグループ「コンポジターノード.001」で、レンダーレイヤー →「グループ出力」とビューアーにつながる
- デモの順: ビネット → 色収差 → グレア 2 種のミックス → ノイズ → シャープ → 露出
- 【画面】Chromatic Aberration: スケール、係数 0.104
- 【画面】グレア「光の筋」: 品質 中、しきい値 0.540、スムーズ 0.100、強さ 1.000、彩度 1.000、光の筋 4、光の筋の角度 0°、回数 3、フェード 0.900、色変調 0.250
- 【画面】グレア「フォググロー」: 品質 中、しきい値 0.350、スムーズ 0.100、強さ 1.000
- 【画面】2 つのグレアをミックス（ミックス、係数 0.500）で合成 →【話者】両方の効果を取り入れられる
- 【画面】Sensor Noise: 輝度ノイズ 0.290、クロマノイズ 0.050、アニメ付き オフ
- 【画面】Unsharp Mask: 半径 3.7、係数 0.07 付近（画面端で切れており要確認）。【話者】しきい値と係数を下げ、色の強さも下げる
- 【画面】色収差の左に 0.751 / 0.892 の値を持つノードがある。ビネットと見られるが要確認
- 【話者】露出は最初に調整してもよい
- 【事実】コンポジターのバックドロップは V で縮小、Alt+V で拡大

## 判断基準

- 写真で済むか: 遠景・平らな面・透過できる植物は写真のまま。近景で角度が変わる物は写真に合わせてモデリング
- ディテールの量: 写真を貼るならモデルは大まかでよい（商品棚はベベル付きの箱程度）
- ランダムさ: 完全な平行・垂直・規則的な並びが残っていないかを見る
- 質感の借り方: 欲しいのが色か、粗さか、凹凸か、マスクかを決めてから写真をつなぐ先を選ぶ
- ライティング: 影が面をまたいでつながっているか。画面外に遮蔽物を置く余地はないか
- コンポジット: 各加工は単体で気づかない程度にとどめる（色収差は「ごくわずかに」とスライドに明記）

## 落とし穴

- 写真をそのまま置くと周囲から浮く → 透過・彩度調整・HDRI の空色のオーバーレイでなじませる
- 平面の透過画像は斜めから弱い → ループカット＋プロポーショナル編集で少し立体にする
- 頂点移動や面の拡大縮小で UV が伸びる → 「面の属性を補正」系のオプションを有効化(表記要確認)
- ナイフを先に使うとループカットが入りにくくなる → ナイフは最後に
- 粗さマップの黒が 0 のままだと鏡面のように極端になる → 黒を少し持ち上げる
- 重ねた画像が繰り返し表示される → 画像テクスチャの拡張を「クリップ」に
- グラスの板の表示がおかしい → 法線の向き。Shift+N で再計算
- 撮影時に汎用的な壁の領域がないと、写っていない面を作れない → 撮影段階で広めに写す
