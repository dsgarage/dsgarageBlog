# Day2 S1「短時間で心を掴む！自主制作から学ぶ、魅力的なショート映像制作」Skill 化用ノート

出典: Blender Fes 2026 AW Day2「短時間で心を掴む！自主制作から学ぶ、魅力的なショート映像制作」（福田泰崇 / 株式会社FUKUPOLY、2026-09-27 10:00–11:00）。
凡例: 【話者】= 講演者の意見・運用上の判断、【事実】= Blender の一般的な仕様、【画面】= 配信画面で確認した値。聞き取りが不確かなものは「(要確認)」。

## 前提・環境

- 【画面】講演は収録映像で、画面上部に章タイトル字幕が出る形式
- 【画面】GAUNTLET OF GODS 作品のレンダーエンジンは Cycles（GPU Compute、Viewport Noise Threshold 0.2 / Max Samples 512、Render Noise Threshold 0.02 / Max Samples 2048、Denoise は OpenImageDenoise・Albedo and Normal）
- 【画面】MV「〜↑↑ -KARAAGE-」の制作画面は EEVEE
- 【画面】画面のサイドバーに Blenderkit、Shaders Plus、Ucupaint、Q-Baker、Easy Decal、Quick Tools などのアドオンのタブが見える(講演中の言及はなし)
- 【話者】コンポジットは After Effects。煙・爆発・粉塵は Nexus for Blender(表記要確認)で作成

## 制作の進め方(判断基準)

- 【話者】アイデアが出ないときは外部のコンペ・期限付きチャレンジ・コミュニティのお題に参加し、「未完成でも期限内に出す」環境を作る
- 【話者】制約を先にルール化する(例: 1 シーン 5 秒、使用アセット数の上限、制作は休日 1 日のみ)。迷う余地を減らしてアイデアを尖らせる
- 【話者】過去の没案や諦めたカットを、今のスキル・新しいツールで作り直す
- 【話者】リアルに作る部分(目立つパトランプなど)と手を抜く部分のバランスを決めてから作る
- 【話者】作品規模の目安: GAUNTLET OF GODS 作品は仕事の合間に約 20 日間。モデルやテクスチャ(看板・点滴バッグ・バイクのラッピング)も Photoshop / Illustrator で自作

## 手法 1: エッジを利用したモデリング(パイプ・配線・フレーム)

- 四角形のメッシュプレートで全体の形を整える → 必要なエッジを選択 → 複製(Shift+D)・分離(P) → メッシュをカーブへ変換
- 角にフィレットを入れて丸める(フィレットの操作方法は要確認)
- 【事実】カーブのオブジェクトデータプロパティ「ジオメトリ > ベベル > 深度」でチューブ状の太さを付けられる(講演では「半径を設定」と表現。どのプロパティかは要確認)
- 【話者】頂点を動かせば後から経路を微調整できる。面から作るのでシルエット・ボリュームを把握しやすい
- 【話者】学校の椅子程度なら 1 脚約 1 分で作れる
- 応用: ソリッド化モディファイアーと組み合わせて蓋の取っ手。カーブの分割数で滑らか/角張った形を切り替え
- 応用: 「カーブに沿って複製」系のモディファイアー(配列＋カーブと見られる、要確認)で手すり

## 手法 2: マテリアルでベベル

- 【話者】エッジが大量にあるモデル(エンジン、石垣など)に実ベベルを入れるとポリゴン数が爆発する → シェーダーで角を表現
- 入力 > ベベルノードを追加し、プリンシプル BSDF のノーマルにつなぐ。サンプル数と半径を調整
- 【事実】ベベルノードはレンダー時に角の法線を丸めるもので、Cycles 専用(EEVEE では効かない)
- ボロノイテクスチャの距離出力 → ベベルの半径 → 角の欠け方が不規則になる
- 【話者】ボロノイのランダムさを 0 にすると角付近に格子状の陰影が出る(用途は未定だが面白い)
- 角の擦れ表現: テクスチャ座標のノーマル＋もう 1 つのベクトル(ベベルの法線と見られる、要確認)→ ベクトル演算「内積」→ カラーランプ → ミックスシェーダーの係数。もう一方に別の色のマテリアル → 角が擦れて下地の色が露出する
- 【画面】内積 → カラーランプ(RGB / リニア)の構成を確認

## 手法 3: 疑似流体

- 【話者】流体シミュレーションは計算とベイクが重い。背景やワンカットならブーリアンとマテリアルアニメーションで済ませる
- 瓶の液体: 液体メッシュにブーリアンモディファイアー(差分)、オペランドに立方体。立方体の上下で水位を変える
- 【画面】ブーリアンは Difference / Operand Type Object / Solver Exact。水位オブジェクト名は pee_level
- 水平維持: 水位の立方体にトラック系のオブジェクトコンストレイントを付け、下方向に置いたオブジェクトを常に向かせる → 瓶が傾いても水面が水平(コンストレイントの種類は要確認)
- 点滴バッグ: 厚みのない板状メッシュを透明なバッグの中に入れる → 屈折で中身が満杯に見える
- 液量: 液体のマテリアルに透明シェーダーをミックス、係数にグラデーションテクスチャ＋カラーランプ → 見た目の液量を増減
- 水面の揺れ: ボロノイテクスチャで波打たせ、UV の位置をアニメーション
- 炎: 炎のレンダリング画像を連番テクスチャで 1 枚の板に貼り、炎以外を透明に。瓶にペアレント。ベンドモディファイアー(シンプル変形の曲げと見られる、要確認)で曲がり方を調整

## 手法 4: キーフレームに頼らないアニメーション制御

- 数式: 放射の強さにドライバー。聞き取りでは `#10*sin(frame/3)**10` に相当する式(要確認)。数値で点滅速度を変える
- 【事実】sin を偶数乗すると 0〜1 の間で鋭いパルス状の波になる
- カーブのノイズ: 強さにキーフレームを 1 つ打つ → グラフエディターで F カーブモディファイアー「ノイズ」を追加 → 値を調整
- 【話者】カーブのノイズはタイムライン上で明滅を目視でき、調整しやすい
- ノイズテクスチャ: 放射の強さ ← 数式「乗算」← 数式「より大きい」← ノイズテクスチャ ← 数式「加算」← オブジェクト情報の「ランダム」(加算の出力をノイズのどの入力に入れるかは要確認)
- 加算の値をキーフレームや数式で増減すると点滅になる
- 【事実】オブジェクト情報のランダムはオブジェクトごとに異なる値を返すので、複製すると点滅がばらつく
- 光の色にもランダム値をつなぐと、1 つのマテリアルで色と点滅がばらつく
- 【話者】見た目が似た点滅でも、仕込み方で後の制御のしやすさが大きく変わる。適材適所で使い分ける

## 手法 5: Link の活用

- 【話者】全要素を 1 つの .blend に詰め込むと重くなり、修正時に破綻する
- マスターのアセットファイルを作り、本番シーンにはファイル > リンクで配置
- 【事実】リンクしたデータは元ファイルを修正すると、開き直した全シーンに反映される。本番側では直接編集できない(ライブラリオーバーライドが必要)
- 実例: 背景のビル群・パトカー・警備車・バイク・老人のロボ・警察官を別ファイルで作り、最後に本番シーンへリンク

## 手法 6: コンポジット(After Effects)

- レンダリングは EXR 連番(多くの情報を持てる形式)か、要素ごとのマスク付き連番で書き出す
- 実例の分け方: 背景 / バイク / 老人のロボ / 爆発 / 水しぶき / 光る部分のマスク
- グローは背景とバイクで分け、強度と広がり方を変える
- カラーグレーディングは Lumetri カラー。暗部を締め、全体を少し青寄りにして爆発のオレンジと対比
- 爆発時に明るさを変えて明順応(表記要確認)のような効果。レンズフレア素材を重ねる
- 【画面】After Effects の作業カラースペースに ACEScg 系の表示がある(要確認)。レイヤー名に light adaptation
- 【話者】11 レイヤーを基本に、細部はマスクで修正し、最終的に約 20 レイヤー

## 手法 7: EEVEE を使った表現

- 【話者】Cycles で数十分〜数時間のレンダリングを待つ代わりに、EEVEE の特性を理解しコンポジットと組み合わせて数秒〜数分に抑える
- 【話者】完成時に近いイメージを見ながら制作できる。レイトレーシング対応で絵もきれい
- 【事実】EEVEE のレイトレーシングは Blender 4.2 以降(EEVEE Next)で利用できる
- 【話者】透明マテリアルは工夫が必要。お酒のボトルは点滴バッグと同じ板メッシュ方式で内容物の増減を表現
- 【話者】鶏の羽がむしられる表現: 羽はジオメトリノードで本体に植えてあったので、パーティクルではなくノードの位置と回転の制御だけで表現

## 手法 8: ジオメトリノードで作る動かし小物(電飾)

- 用意: 電飾のコードになるカーブ、電球のモデル(コレクションにまとめる)
- ノード: オブジェクト情報(カーブ)→ カーブのリサンプル → ポイントにインスタンス作成。インスタンスにコレクション情報(電球のコレクション)
- 【画面】コード部分: カーブのリサンプル → カーブをメッシュに(プロファイルにカーブの円)→ マテリアル設定 → ジオメトリを統合 → グループ出力。コレクション情報は Separate Children / Reset Children オン、ポイントにインスタンス作成は Pick Instance オン
- 【画面】モディファイアーに公開した入力: led_pitch / line_Radius / rotate_power / rotate_speed / led_scale
- リサンプルのサンプル数(または長さ)で電球の数を変える
- 点滅はアニメーションカーブのノイズでランダムに
- インスタンスの回転にノイズを加えると風になびく表現になる
- 【話者】背景の小物はノードで自動化するのが物量をこなす最大の近道

## 落とし穴・注意

- 【事実】マテリアルのベベルノードは Cycles 専用。EEVEE 主体の作品では効かない
- 【話者】疑似流体の点滴バッグは屈折頼みなので、透明マテリアルの扱いは EEVEE では追加の工夫が必要だった
- 【話者】仕込み方(数式 / カーブ / テクスチャ)を最初に決めないと、後の制御や一括変更で時間を失う
