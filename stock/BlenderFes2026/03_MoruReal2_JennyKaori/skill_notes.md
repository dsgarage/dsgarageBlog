# S3 skill_notes: 盛る3D制作（ジェニーカオリ）

Skill 化の素材。【事実】= Blender の一般的な仕様・確認できる事実、【話者】= ジェニーカオリさんの意見・個人的な手法。聞き取りが不明確な箇所は「(要確認)」。

## 環境・ツール

- 【事実】配信画面に映った制作データは `final.blend`、タイトルバー表記は Blender 4.5 系 LTS（細部の版数は画面が小さく要確認）。シェーディングワークスペースで作業している
- 【話者】リグは Auto-Rig Pro（有料アドオン）を使う。それ以外のアドオンはほぼ入れない。理由は「入れたらそのアドオンの使い方を覚える必要があり、面倒」
- 【話者】服は Marvelous Designer で型紙（身頃・袖丈）から作る。アパレルの知識があると形の説得力が出る
- 【話者】背景に実写の渋谷写真を置いている様子が画面に映っている（カメラ背景画像か、プレーンに貼った画像かは要確認）

## 2D 作家の 3D 入門（プレーン方式）

- 【話者】描いた絵を透過 PNG にしてプレーンに貼り、飛び出す絵本／ペーパークラフトの要領で空間に立てる。背景のビルも絵で作る。モデリングなしで 3D 空間の構図・カメラを試せる
- 【事実】Blender では「画像を平面として追加」（Import Images as Planes、4.2 以降はコア機能として Add > Image > Mesh Plane）で透過画像をアルファ付きのプレーンとして読み込める。アルファを効かせるにはマテリアルの Alpha 接続を確認する
- 【話者】当初はアウトライン 1 本付けるのにも苦労した。イラストの「線を描く」感覚は 3D では「線を実装する」作業になる、と意識を切り替える必要がある

## 企画・ラフの手順

- 【話者】ブリーフの形容詞（例: 抜け感のある平成、トレンド感）が矛盾していても、言いたい雰囲気を分解して読む。矛盾は「空気感」と「要素」に振り分けると両立できる
- 【話者】あいまいな時代感ワードは自分の文化的な整理軸に当てはめる。例: 平成 A 面（ギャル・SHIBUYA109・Y2K）／B 面（セゾン系・PARCO 広告・STUDIO VOICE・渋谷系）。「抜け感」は B 面
- 【話者】リファレンスは自分から集めるより、クライアント提供分を中心にする。解釈に迷ったら担当者に「こっち系ですか」と二択で確かめる
- 【話者】ヒアリング後に着地点のラフを 1 枚描く。書く項目: 人数、文字の配置、避けるもの（例: レイブ感）、カメラと被写体の距離・前後差、キャラ設定のメモ。三面図は作らない。迷ったら戻る「地図」として使う
- 【話者】キャラ設定は出演者・依頼内容から逆算する（例: ポエトリー系の出演者 → 眼鏡の文学少女風）
- 【話者】背景のランドマークは「今」を示すものを選ぶ。有名でも今っぽくないものは外す（SHIBUYA109 より再開発の高層ビル群と映り込む空）。なくなった店舗の入っていたビル等、移ろうものはノスタルジー表現に使える

## 要素（object）と空気感（environment）の分離

- 【話者】服・アクセサリー・髪型・ネイルなどのオブジェクトにはトレンド（例: ピンク×ミントグリーン、ドット）を入れる
- 【話者】時代感（例: 平成っぽさ）はライティングとコンポジットの「空気」で全体を包んで出す。Instagram のノスタルジー系フィルターと同じ理屈で、今撮った写真も空気で懐かしくなる
- 【話者】この分離により、画面内の要素を増やしても時代感が破綻しない
- 【話者】シェーダーは要素（モデル・マテリアル）と空気感（環境）の間を取り持つ層として設計する。キャラの「らしさ」はオブジェクトの形よりシェーダーで入れる
- 【話者】最終レンダーはフィルター（ぼかし等）がかかる前提。データ上の細部とレンダーの見え方は別物として扱う

## Layer Weight ノード（中核テクニック）

- 【事実】Layer Weight ノード（Input > Layer Weight）は入力 Blend / Normal、出力 Fresnel / Facing を持つ。面の法線と視線方向の角度から 0〜1 の値を出すため、カメラを動かすと値が変わる
- 【事実】Facing は正面を向いた面で 0、視線と平行な輪郭側で 1 に近づく。Blend を上げると輪郭側の範囲が広がる。Mix Color の Factor や ColorRamp の入力に使うと、縁だけ色を変えられる
- 【話者】カメラに追従して光の重なり方が変わるもの、と独学で理解して使っている（正確な仕組みは各自で調べてほしい、とのこと）
- 【話者】瞳: Layer Weight で黒目の範囲と色の移り変わりを作り、マグネットネイルのように視点で色が動く瞳にする。カラコンらしさは縁側に複数色を入れて出す。キャラごとに「この子はどういうレンズが好きか」で色を変える
- 【話者】髪: 黒髪でも縁に空の青（環境色）を Layer Weight で混ぜ、重く見えない「抜け感」と軽やかさを出す
- 【話者】肌の縁: ピンク（ワクワク感）やブルーのラインが縁に残るよう混ぜる。2D イラストで肌の輪郭をピンク／オレンジにする描き方をシェーダーで再現したもの
- 【話者】「うるちゅる感」（ネイル・髪・肌・レンズに共通するトレンド質感）は Layer Weight 中心のシンプルな構成で出せる
- 【話者】Layer Weight はほぼすべてのマテリアルに使っている。シェーダーの勉強で球体に貼るレベルの基本ノードを応用するだけで十分な個性が出る

## 肌・化粧

- 【話者】肌のシェーダーをイエベ（イエローベース）／ブルベ（ブルーベース）で分ける。キャラ設定と連動させる（眼鏡の子 = ブルベ）
- 【話者】化粧テクスチャは 2 キャラで同じ画像を使い、Hue/Saturation ノードで色を変えるのではなく、シェーダー内で色をミックスして差を出す（ミックスの具体的なノード構成は要確認）
- 【話者】流行の古さ・新しさは前髪・眉・化粧（チーク位置、ハイライト位置）に最も出る。眉は薄眉の今っぽい形にする
- 【話者】アウトライン（輪郭線）にはキャラの性格らしさを表す別の色を入れる（アウトラインの実装方法は配信では明言なし、要確認）

## 質感・ディテールの判断基準

- 【話者】服は「洗いこんだ古着」の解像度で作る: プリントのはげ、毛羽立ち、張りのないプリーツのヨレ
- 【話者】髪型は平成っぽい深いレイヤーカット、プリン（根元の地毛）がない染め方など、時代の記号を入れる
- 【話者】服に案件名（例: PAKiPOKi）を仕込むなど、制作を自分が楽しむ遊びを入れる
- 【話者】トレンドは日常的にスクリーンショット・メモで収集しておく（例: フィギュアスケート選手の髪型、SNS で話題の肌色の話）(髪型の名称は要確認)

## 学習・運用

- 【話者】ベースの体（アバター的なボディ）を 1 体作れば、髪型・服を差し替えて使い回せる。トポロジーを整えるために作り直すことはある
- 【話者】三つ編みはカーブで編むか、ジオメトリーノードで生成するか（要確認）。この種の「2D なら 30 分」の要素で挫折しやすい
- 【話者】独学初期は絵に逃げないよう、描ける自分をいったん忘れて取り組んだ
- 【話者】エラーやファイル破損時に聞ける場（Discord の初心者コミュニティ、Blender Fes など）がモチベーション維持に重要
- 【話者】AI はプロップの土台づくりなど、時間・予算に応じて複合的に使ってよい。ただし作品の中心（服のヨレ具合など感性が出る部分）は手で作る
