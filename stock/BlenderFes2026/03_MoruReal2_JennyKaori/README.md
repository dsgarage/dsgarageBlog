## 概要（チャンネルページより）

「なんかゥチ、これ好き🌺もっとこういうものが現実にあったらいいのに🌺🌺🌺」 そんな個人的な「好き」や「欲しい」を出発点に、Blenderで世界をつくってみる。 個人制作だからこそできる、制約のない自由な創造性。その中で、現実をそのまま再現するのではなく、**現実にありそうで、現実には存在しない“リアル²”**を目指そ☝️ 車やSF、リッチなアニメーションだけが3Dじゃない。「ガーリー」「ファッション」「カルチャー」「ファンシー」「日常のちょっとした妄想」まで。 大事なのは＜ゥチ的創作態度＞。「自分が見たい現実以上を、自分でつくる」。Blenderで広がる表現の可能性を作品とともに考えます。
