# S2 要点: 絵作りと効率を両立させる、キャラクターシェーディング技法（三縁エイト）

- 約21分・200カットの『砂塵ノ中デ』を9割以上個人で制作。1カット10分の追加は全体で約33時間になるため、「80%を200カット安定して出す仕組み」を優先した
- 方針は「絵を描くときの無意識の判断を条件と処理に分解し、シェーダー/ジオメトリーノードで再現する」こと
- 個人制作でセルルック3DCGを選ぶと商業作品の劣化版になりやすいと判断し、「ゲーム系リアルタイムシェーダー × イラスト調ルック」を採用
- 3DCGは線より塗り（テクスチャと造形の一貫性）が得意な媒体という見立てで、柔らかい塗り中心のルックにした
- Blender カスタムビルド Goo Engine 4.1 を全編で使用。Shader Info（陰・落ち影・ライトグループ別の分離）と Curvature の Scene Rim（スクリーンスペースの輪郭マスク）が中核
- リムライトはカメラ基準の左右マスク（ジオメトリーノードで渡した部位基準位置とカメラ横ベクトルの内積）で片側だけに出し、色は AE で付ける
- Active Camera ノードで動かす2頂点の棒とエンプティを介し、どのカメラでもリムライトが追従する仕組みを作った
- 顔は複数 SDF（RGB に追加マスク）+ ブラー、髪の法線は顔=DataTransfer 保持・髪=ジオメトリーノード生成で使い分け
- 前髪の落ち影は複製メッシュ + Screenspace Info、髪越しの目は半透明の複製 + Set Depth、影境界の色と影側の反射光はずらした陰影の差分とライトベクトル・法線の内積で作る
- 約3年ほぼ1人の制作を振り返り、お金と人の不足はアイデアとワークフローで覆せると締めくくった
