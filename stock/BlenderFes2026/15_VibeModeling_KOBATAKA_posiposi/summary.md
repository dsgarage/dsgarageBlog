# S7「AIエージェント × Blenderで挑む Vibe Modeling」要点（KOBATAKA、posi_posi）

- Vibe Modeling は自然言語で AI エージェントに Blender を操作させるモデリング。100 点ではなくたたき台・イメージ確認に使う（事前収録、収録日 9/5 時点の評価）
- 構成は Claude Code / Codex ＋ Blender MCP（対話）と `blender -b --python`（長処理・本番レンダー）。AI が自分のレンダーを画像で見て直す「手と目」のループが転換点
- 得意は数値で言い切れる形・繰り返し（歯車・らせん階段・本棚）。苦手は有機形状・部品の接続・物理量（顔・犬・配管ラック・山岳地形）。有機物は Tripo 等のメッシュ生成と分担
- 反復は「一発生成 → 参照画像と比べて自己改善 → 専門知識を注入 → 数値仕様書と AI 画像監査（PASS/FAIL）」。木は 11 ラウンド
- AI はゴールを知らず、決めていない値は最小コストで埋める（「マグカップ」→塞がった円筒）。寸法・専門用語・機能名（Bevel/Array）で指定する
- 作る AI とツッコむ AI（サブエージェント）を分ける敵対的レビュー。形の背景にある理由を先に考えさせると抜け漏れが減る
- 手順は 目的 → Web で専門知識調査 → 作業仕様 → 実行 → AI 検査 → 人の確認。不明点は AI から人間へ質問させる
- 経験は LLM wiki・スキル・メモリーに外部記憶として蓄積。人間向けチュートリアルを AI と解く、1000 体を 100×10 ラウンドで作る、で経験値を積む
- Blender 5.x の API 差分（GN モディファイアー入力の書き方）で AI は転ぶ。「実行できた」と「反映された」は別なので、まず実行して確認
- 人は決定・基準・品質判断・責任、AI は作業と検査の実行。始めるなら自分が判断できる分野で、Codex または Claude Code ＋ Blender MCP から
