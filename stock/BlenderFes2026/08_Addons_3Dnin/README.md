## 概要（チャンネルページより）

大好評企画「3D人が選ぶ注目のBlenderアドオン」第7回！ 今回のゲストは、cvELDの主宰で、Blender向けリギング補助アドオン「 cvELD_QuickRig 」「 cvELD_QuickBBone 」の開発者としても知られるLand-Y氏。 長年にわたるリギング・アドオン開発の経験を持つ氏の視点から、 選りすぐりのアドオンをピックアップし、その活用法や魅力を徹底的に語っていただきます。 プロならではの厳選アドオンと、その選出理由をたっぷりと語る本企画。 制作現場の生の声が詰まった、ここでしか聞けない情報満載のセッションをどうぞお見逃しなく！
