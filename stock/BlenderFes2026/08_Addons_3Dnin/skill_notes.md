## アドオン / ツール一覧

### 1. VRM Add-on for Blender
- 用途: VRM 形式のキャラクターのセットアップ、読み書き
- 対応バージョン: 不明（セッション内で言及なし）
- 入手先: 不明（セッション内で言及なし。Blender Extensions 等で配布）
- 使いどころ: ゲーム制作で人型キャラクターを VRM 規格でセットアップする
- 落とし穴: 言及なし
- 推薦者: ますく

### 2. Auto-Rig Pro
- 用途: 自動リギング。人型以外のキャラクターにも利用
- 対応バージョン: 不明
- 入手先: 有料（Superhive 等）
- 使いどころ: 人型以外のキャラクターのリグ作成。AI から MCP / CLI 経由でオペレーターを呼び出して操作した実例あり
- 落とし穴: AI から呼ぶには、機能がオペレーターとして定義され、AI 側から分かる状態である必要がある
- 推薦者: ますく

### 3. Tripo DCC Bridge
- 用途: Tripo（画像やテキストから 3D モデルを生成するサービス）の生成物を Blender へ直接送る
- 対応バージョン: Blender 4.1 以降（配布元の記載）
- 入手先: https://www.tripo3d.ai/integrations/blender
- 使いどころ: イラストから起こしたモデルを Web 側の操作ひとつで Blender に取り込み、ウェイトやアニメーションを付ける
- 落とし穴: 言及なし
- 推薦者: ますく

### 4. SkinTokens（TokenRig）
- 用途: 人型以外も含むメッシュに、骨格とスキンウェイトを自動生成する研究モデル。UniRig の後継
- 対応バージョン: 該当なし（研究コード）
- 入手先: https://github.com/VAST-AI-Research/SkinTokens / https://zjp-shadow.github.io/works/SkinTokens/
- 使いどころ: 四足動物などに骨とウェイトを入れる。AI 生成の動画から骨格を検出してモーションを付けた例あり
- 落とし穴: 個人で環境構築するのは難しい研究コード。AI にセットアップを任せて動かした。登壇者は ComfyUI をローカル AI の実行基盤にし、Blender から呼び出す二重構造にしていた
- 推薦者: ますく

### 5. HY-Motion (表記要確認)
- 推定公式名: Tencent Hunyuan「HY-Motion 1.0」（文字起こしでは「テンセントのHIMモーション」）
- 用途: テキストから 3D キャラクターのモーションを生成する
- 対応バージョン: 該当なし（モデル）
- 入手先: https://github.com/Tencent-Hunyuan/HY-Motion-1.0
- 使いどころ: 「回ってジャンプする」のような文章からアニメーションを作る
- 落とし穴: 自力でのセットアップは難しく、AI に構築させた
- 推薦者: ますく

### 6. 動画生成 AI「ミニマックス H3」(表記要確認)
- 推定公式名: MiniMax の動画生成モデル（Hailuo 系と推定。未確認）
- 用途: モーション参照用の動画を生成する
- 対応バージョン / 入手先: 不明
- 使いどころ: 四足動物が走る動画を生成し、骨格検出の素材にする
- 落とし穴: 言及なし
- 推薦者: ますく

### 7. Blender MCP（Blender Lab MCP Server ほか）
- 用途: 対話型 AI から Blender を操作する受け口。Model Context Protocol に対応
- 対応バージョン: 不明
- 入手先: https://www.blender.org/lab/mcp-server/（公式）。コミュニティ製も多数ある
- 使いどころ: 崩れたウェイトを直させるなど、シーンの操作・診断・相談
- 落とし穴: 実装ごとに得意不得意があり、作業に応じて選ぶ必要がある（どれを使うか AI に相談する、という助言）。公式ドキュメントは、生成コードを保護なしで実行する点についてセキュリティ上の注意を出している
- 推薦者: ますく

### 8. Blender の CLI 実行（逆アドオン）
- 用途: Blender を画面なしでコマンドから起動し、機能だけを呼び出す（`-b` でスクリプトを実行）
- 対応バージョン: Blender 本体の機能
- 入手先: 該当なし
- 使いどころ: Unity 等の別プロジェクトから、Blender を開かずに UV 展開などの処理を呼ぶ。外出先からチャット経由で自宅 PC の Blender / Unity を動かす
- 落とし穴: 言及なし。まとめスライドでは「使っているアドオンで `dir(bpy.ops.〇〇)` を打つ」ことを最初の一歩として勧めていた
- 推薦者: ますく

### 9. Poly Haven アセット / オンラインアセットライブラリ
- 用途: テクスチャ・マテリアル等の素材をアドオンや本体機能から取り込む
- 対応バージョン: オンラインアセットライブラリは「Blender 5.2 から」と発言（表記要確認）
- 入手先: https://polyhaven.com/
- 使いどころ: 背景テクスチャを手早く当てる
- 落とし穴: 言及なし
- 推薦者: ますく

### 10. Field-Aligned Surface-Filling Curve
- 用途: メッシュ表面を 1 本の連続したカーブで埋め尽くす
- 対応バージョン: Blender 4.5 との連携を論文ページで記載
- 入手先: https://github.com/iota97/Surface-Filling-Curve（無料、`blender_addon.py`）
- 使いどころ: 生成エッジをカーブに変換し、ジオメトリーノードでチューブ化する。木目柄、一筆書きの構築アニメ、3D プリント用アクセサリー
- 落とし穴: 公式配布の実行ファイルは Windows のみ。アドオンで exe のパスを指定して使う。細かく設定すると処理時間が延びる
- 推薦者: 3D人

### 11. ZOZO PPF Contact Solver
- 用途: めり込みにくい布・ソフトボディのシミュレーション
- 対応バージョン: Blender 5.0 向けアドオン（配布元の記載）
- 入手先: https://github.com/st-tech/ppf-contact-solver（Apache License 2.0）
- 使いどころ: 重ねた布、結び目など自己衝突が多い布表現。ベイクすると頂点の動きが全フレーム分のシェイプキーになり、他環境へ持ち出しやすい
- 落とし穴: 最初から自己交差しているメッシュはエラーで弾かれる（スザンヌ、ポーズを付けたキャラクターの脇、裏返った面）。回避策はリメッシュ、または軽量メッシュでシミュレーションしてからケージで変形させる
- 推薦者: 3D人

### 12. SplatGen
- 用途: Blender シーンから 3D ガウシアンスプラッティング（3DGS）データを作る
- 対応バージョン: 不明（デモ画面は Blender 5.2.0 LTS）
- 入手先: https://superhivemarket.com/products/splatgen（無料版 / 有料 Pro 版。作者 Jellyfish Studio）
- 使いどころ: 背景をベイクして軽く見せる。スマホや VR のコンテンツ。ライトマップの代替
- 落とし穴: 無料版はデータセット作成まで。Blender 上での学習は Pro 版（NVIDIA CUDA GPU が必要）。アドオンは約 3GB で処理が長い。実写写真の位置合わせ用途ではない。アップでは粒が目立つので遠景向き。価格「0.33ドル」の発言は聞き取り要確認
- 推薦者: 3D人

### 13. UVgami
- 用途: 自動 UV 展開。xatlas（CPU・高速）、OptCuts（CPU・低歪み）、PartUV（GPU・パーツ単位）を切り替えて使う
- 対応バージョン: 不明
- 入手先: https://github.com/DanielBoxer/UVgami（無料）
- 使いどころ: とりあえず開きたいとき。OptCuts はウェイトペイントで切る場所の優先度を制御できる
- 落とし穴: 完璧ではなく実験的。外部処理のためメッシュが三角形化される（UV 転送オプションで元メッシュに戻せる）。PartUV は GPU と CUDA 環境に依存し、手元では最初は動かなかった。顔などの目立つ場所にシームが入ることがある
- 推薦者: 3D人

### 14. INSYDIUM NeXus for Blender
- 用途: GPU で動くパーティクル・流体・炎・煙のシミュレーション
- 対応バージョン: Blender 4.3 以降、VRAM 4GB 以上（配布元の記載）
- 入手先: https://insydium.ltd/products/nexus/（有料。発言では 3 万円弱、12 か月アップデート付き買い切り）
- 使いどころ: 1 つのパネルに機能をスタックして管理できる。プリセットから炎や水をすぐ作れる。ノート PC の GPU でも炎はほぼリアルタイム
- 落とし穴: 流体の粒子を細かくしたりメッシャーでメッシュ化したりすると重い。粗い設定でテストしてから解像度を上げる
- 推薦者: 3D人

### 15. cvELD_ShellFit
- 用途: 素体と衣装の貫通を見つけて押し戻し、シェイプキーまたはメッシュに焼き込む
- 対応バージョン: v1.2 告知では Blender 4.5 対応（一部機能制限あり）。Superhive の記載では 4.5〜5.2
- 入手先: https://cveld.booth.pm/ / https://superhivemarket.com/products/cveld-shellfit（有料）
- 使いどころ: VRChat 向けなどの着せ替え衣装の調整
- 落とし穴: 機能が多く、マニュアルなしでは難しいと感じる人もいる
- 推薦者: Land-Y（開発者本人）

### 16. cvELD ShellFit Brush

- 対応バージョン / 入手先: 不明（cvELD の BOOTH を参照）

- 落とし穴: ShellFit 本体とはできることが根本的に違うため、両方あるとよいという位置づけ
- 推薦者: Land-Y（開発者本人）

### 17. cvELD Schematic View

### 18. cvELD_QuickRig
- 用途: ボーンを素早く生成・調整するリギング補助
- 対応バージョン: 配信画面の BOOTH 記載では Blender 5.2 / 4.5 にインストール可能（v5.1.1）

### 19. リミナルウォーカー (表記要確認)

## 登壇者が語ったアドオン選定・開発の判断基準

- 既存アドオンを AI から使うなら、機能がオペレーターとして定義されているかを確認する（`dir(bpy.ops.〇〇)` で調べる）
- MCP は実装ごとに得意不得意がある。作業内容に合わせて選び、迷ったら AI に相談する
- 使い道が決まっていなくても、「こういうことができる」と知ること自体に価値がある。論文由来の技術は後で応用先が見つかる
- 論文をアドオン化する前に、アドオン化に向くか、依存関係、ライセンス、Blender からの使いやすさを AI に調べさせて比較する
- ライセンスが「要問い合わせ」の技術は、販売や配布の前に開発者へ連絡する。それまでは手元の実験にとどめる
- 処理速度が実用に届かない技術は、トークンと時間を溶かす前に見切る
- 論文の結果を再現できるかを、論文と同じサンプル形状で先に確かめる
- 形状が崩れたら、AI に画像を撮らせて問題箇所を判断させ、修正を繰り返させる
- 高性能な AI には設計と判断（「どこが顔か」など）だけを任せ、実行は安いモデルやオープンモデルに回すとコストを抑えられる
- 調査・相談と実装・テストでツールを分け、トークンの無駄な消費を避ける
- シミュレーションは粗い設定でテストし、ベイクしてから解像度を上げる
- 長年の開発経験があるメーカーのアドオンは、UI の分かりやすさ、プレビューの速さ、パネルの統一で差が出る。価格は専門用途なら妥当と判断できる
- アドオンは仕組みよりも、使い勝手、エラー対策、例外条件の洗い出しに時間がかかる。AI が作る UI は他人には使いにくいことが多いので、スクリーンショットを見ながら手で直させる
- ユーザーがマニュアルを読まない前提で、ブラシのような直感的な入口を別に用意する
- 自分が欲しいツールだけでなく、市場の需要（例: VRChat の衣装づくり）も見て作る
- AI 時代でも、CG の基礎知識があるほうが良い結果を出しやすい
- 思いついたアドオンは並行して試作しておく（Land-Y さんは 10 本以上を同時進行）。デバッグだけに時間をかけず、粗くても使ってもらって反応を見る
- 販売チャネルは手数料も比べて選ぶ。Land-Y さんは主に BOOTH で販売し、マーケットの手数料の高さに触れていた
- 専門家が作ったアドオンは細かな要望に応えてくれる。自分でできないことは AI でアドオン化する。この 2 つを使い分ける（3D人さんの締めの言葉）
