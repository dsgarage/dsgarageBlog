# Day2 S6「VRChatワールドができるまで」要点（Fujito）

- 制作を「考えるフェーズ（キーワード → ラフスケッチ → リファレンス）」と「つくるフェーズ（ラフモデル → 詳細モデル → VRChat 用に調整）」に分ける
- キーワード（年代・時間・季節・天気・場所・建築・雰囲気）と制約条件で与条件を先に決め、バブルダイアグラムと平面スケッチで空間の関係と体験の順序を描く
- リファレンスは再現せず「構造化」する。要素を抜き出して自分の空間に当てはめる（例: 床に段差をつけてテラスを立体的にした）
- ラフモデルは辺の長さ表示・トランスフォームパネル・人型モデルで身体スケールを確かめ、面の向きの表示で裏面を反転しておく
- Unity は VRChat 対応版（講演では 2022.3.22f1）を VCC 経由で。FBX は選択物のみ・メッシュのみ・パスモードはコピー（埋め込みなし）・FBX すべて・-Z 前方・Y 上・モディファイアー適用
- Unity では Extract Materials、Generate Lightmap UVs、Mesh Collider、Static、部屋ごとの Reflection Probe（Box Projection）、等間隔の Light Probe Group を設定
- ラフモデルの段階で Build & Test し、VRChat の中でスケールと雰囲気を確かめるのが良いワールドへの近道
- 詳細モデルは素材の実寸で UV を合わせ（500 角タイルなら 1m に 2 枚）、小口・目地・枠・天板の厚みなど建築の収まりで実在感を出す。見えない面や重なった面は Blender で消す
- マテリアルは Autodesk Interactive。ラフネスは sRGB オフ、ノーマルは Normal map 指定。ベイクは低サンプルで試してから上げ、黒ずみが残れば UV2 を Blender で用意する
- Post Processing は PC 版のみ有効。公開は New User 以上が必要で、容量は Quest・iOS 対応を見据えて 100MB 以内を目安にする
