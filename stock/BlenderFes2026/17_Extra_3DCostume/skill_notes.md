# 【Blender Fes Extra】3D衣装の作り方 Skill 化用ノート

出典: CGWORLD ONLINE ACADEMY「【Blender Fes Extra】3D衣装の作り方」前半(contents/2152、1:41:31)・後編(contents/2181、1:45:48)、講師はアレイラさん(講座内の呼称)。
凡例: 【話者】= 講師の意見・運用上の判断、【事実】= ソフトの一般的な仕様、【画面】= 講座画面で確認した値や表示。聞き取りや表記が不確かなものは「(要確認)」を付けています(操作ナビの要確認を引き継いでいます)。
表記: Blender は日本語 UI 名を基本にし、英語 UI 名を括弧で併記します。SP = Substance 3D Painter、SD = Substance 3D Designer。時刻は前半が講座動画の時刻(換算値)、後編が校正版文字起こしの時刻です。
Skills 化の入力: claude-code-config#23。

## 前提・環境

- 【画面】講座の Blender は 5.1 です。操作ナビの日本語表記は 5.2 の翻訳ファイルと講座画面で照合しています
- 【話者】最低限そろえるソフトは Blender と SP です。VRChat やゲーム向けなら Unity(VRChat 向けの 2022 系)、lilToon、VRChat SDK も要ります
- 【話者】任意のソフトは次のとおりです。ZBrush(布のハイモデル。Blender スカルプトで代用可)、Marvelous Designer(完成品には不使用)、SD(柄素材)、CLIP STUDIO PAINT(デザイン画、PSD 化)
- 【話者】アドオンは次のとおりです。無料: AutoMirror、EdgeFlow、LoopTools、ScrambleAddon、Mio3 UV、GoB。有料: NgonLoopSelect、Machin3Tools、Quad Remesher、RetopoFlow。ウェイト用: yuzuWeightEditor、Lazy Weight Tool(要確認: 講座では「AZウェイト」と聞こえる)
- 【事実】TexTools は Blender 5.0 以降で動かないため、Mio3 UV(テクセル密度機能あり)で代替します
- 【話者】講座の範囲は Unity での見た目のチェックまでです。揺れ物の設定とアップロード手順は扱っていません

## 工程 1: デザイン決めと分析

### 手順
1. 着せるアバターの素体を正面から撮り、それに重ねてデザイン画を描きます
2. 正面・側面・背面の三面図を用意します
3. 素体の標準ポーズ(T か A)でデザイン画を描き、もう一方のポーズでも確かめます。T で描いたらペイントソフトの変形で腕を傾け、A で描いたら腕を水平にした画像を作ります
4. 構造が分からないパーツの実物画像を集め、PureRef に三面図と並べます。生地や縫い方は詳細図にメモします
5. ポリゴン数、形で作る所とテクスチャに任せる所、テクスチャの枚数と分け方、柄の調達方法を決めます

### 設定値
- 【話者】ポリゴン数は、VRChat の少人数撮影を想定して 8〜10 万以内にしています。イラスト調のゲームなら素体と髪込みで全身 5〜10 万が目安です。VRChat の衣装は 15 万を超えるものもあります
- 【話者】テクスチャは 6 枚です(バラ、トップス、スカート、靴下と靴、骨、ベルトと金属)

### 判断基準
- 【話者】人に描いてもらうなら、腕を下ろした状態に近い A ポーズで頼みます
- 【話者】デザインは「自分が好きな要素」と「受け取る人がうれしい要素」を軸にします。見るべき点は、斜め上からのライトでの影、バストアップでの特徴、近くで見て気づく作り込みです
- 【話者】傾けたときにシルエットに影響しない凹凸はテクスチャに任せてかまいません。慣れないうちは、ベイクの段階で試してから判断します

### 落とし穴
- 【話者】正面図だけのデザイン画は、デザインとモデリングを同じ人がやる場合にしか通用しません
- 【話者】T ポーズのままシワを作ると、腕を下ろしたときに不自然になります

### 開く場所
- ペイントソフト > 変形ツール(自由変形)
- PureRef(画像の並べ貼り)

## 工程 2: モデリング

### 手順
1. 不要なカメラとライトを削除し、ファイル > インポート > FBX (.fbx) で素体を読み込みます
2. アウトライナーでアーマチュアや既存の服を非表示にします
3. 素体の色が出ないときは、ビューポートシェーディングをマテリアルプレビュー(Material Preview)にし、マテリアルタブのベースカラー(Base Color)に画像テクスチャを指定します
4. 色あせて見えるときは、レンダータブ > カラーマネージメント(Color Management) > ビュー変換(View Transform)を「標準」(Standard)にします
5. -Y 視点で Shift+A > 画像 > 参照(Reference)でデザイン画を置き、移動とスケールで素体に合わせます
6. オブジェクトデータタブ > エンプティ > 表示先(Show In)の「透視投影」(Perspective)をオフにし、「不透明度」(Opacity)を下げます
7. アウトライナーのフィルター > 制限の切り替え > 選択可能(Selectable)を表示し、下絵の矢印をオフにします
8. 表示を整えます。照明はフラット(状況で Studio や MatCap)、影をオン、ビューポートオーバーレイ > ワイヤーフレームをオンにします
9. Shift+A > メッシュで近い立体(円柱・UV 球・立方体・平面)を出し、編集モードで S と G を使って下絵に合わせます
10. ループカット(Ctrl+R)や細分化(Subdivide、「Nゴンを作成」をオフ)で頂点を増やし、動かして形を作ります
11. 複雑なパーツは、平面をナイフ(K)でトレースして押し出し(E)、ブリッジや F で隙間を埋め、M でマージします
12. 繰り返しパーツは、配列(Array)モディファイアーとカーブ(Curve)モディファイアーで作ります
13. シルエットを調整し、後工程のための辺・シャープ・格子を仕込みます
14. 最終チェックをします(五角形以上、非多様体、面の向き、法線)

### 設定値
- 【話者】スカートの円柱は頂点数 8〜10、ループカットの分割数は 3 程度です
- 【話者】作り始めの立体は、筒状なら円柱、結び目なら立方体、平たいものや複雑なものなら平面を選びます
- 【画面】五角形以上の面の検索は、選択 > 特徴で全選択 > 面の辺数(Faces by Sides)で、頂点数 4、タイプ「大きい」(Greater Than)です
- 【画面】非多様体は、選択 > 特徴で全選択 > 非多様体(Non Manifold)で「境界」をオフにして探します。次に境界をオンにして、不要な穴を探します

### 判断基準
- 【話者】三面図と合わないときの優先順位は、正面図と斜めの見え方、背面図、側面図の順です。側面図は印象を取り入れる程度にします
- 【話者】全体を引きで見て、角が目立つ所にポリゴンを足します。VRChat 向けなら仮アップロードで確かめます
- 【話者】後工程のため、次の点を仕込みます
  - UV のため: 縫い目や材質の境界に辺を置きます
  - UV のため: 90 度に近い角と材質の切り替わりに、シャープをマーク(Mark Sharp)を付けます
  - ウェイトのため: 面を格子状にし、肩・肘・膝・胸は素体とエッジの位置と本数を合わせます
  - ウェイトのため: 近いパーツや表裏は頂点をそろえます。ボタンの下はバツ印に面を割ります
- 【事実】ゲーム向けモデルは Unity で三角面化されるため、三角面を使ってかまいません
- 【話者】歪んだ四角面や、表裏で三角の向きが違う所は、Blender 上で三角化して向きをそろえます。編集中は四角面で作り、最終チェックで三角化します
- 【話者】有機的な配列パーツは、適用してからプロポーショナル編集でばらつかせます
- 【話者】Marvelous Designer はデザイン画と同じシワを作れません。リアル寄りの衣装や、難しいパーツの参考に使います

### 落とし穴
- 【事実】講師は「フィルミック」から変えていましたが、Blender 4.0 以降の新規ファイルの既定は AgX です。どちらでも「標準」にすれば同じ結果です
- 【話者】非多様体は Blender では通ってしまいますが、UV 展開の失敗や他ソフト連携で致命的になります
- 【事実】「カスタム法線データをクリア」は、カスタム法線を持つメッシュにだけ表示されます
- 【話者】三面図どおりのスカートは、上から見ると四角っぽくなります
- 要確認: 花びらを円形に並べる配列の設定値は講座画面で未確認です
- 要確認: 前半 54:18 付近に、講座動画の約 2 分ぶんの録画欠落があります(三面図の優先順位の説明の途中)

### 開く場所
- 3D ビューポート > サイドバー(N) > 編集(Edit)タブ > AutoMirror
- 編集モード > 右クリック > Set Flow(EdgeFlow)/ LoopTools > Relax(お気に入りツールに追加し Q キーで呼び出す)
- 編集モード > 右クリック > 辺を時計回りに回転(Rotate Edge CW)
- 編集モード > 削除 > 辺や面を統合(Collapse Edges & Faces)。講師は旧訳の「束ねる」と呼んでいます
- 編集モード > Alt+R(Machin3Tools の EdgeConstrained)。ScrambleAddon の「頂点のみを隠す」は Ctrl+Shift+H に登録されています
- ビューポートオーバーレイ > 面の向き(Face Orientation) → Alt+N > 反転(Flip)/ 面の向きを外側に揃える(Recalculate Outside)
- Alt+N > ベクトルをリセット(Reset Vectors)/ オブジェクトデータタブ > 形状データ > カスタム法線データをクリア

## 工程 3: UV 展開

### 手順
1. シャープの辺を 1 本選び、選択 > 類似選択(Select Similar) > シャープで一括選択し、右クリック > シームをマーク(Mark Seam)にします
2. 布は現実の服の縫い目(脇、肩、袖の付け根、脇の下)にシームを足します。分からない形は型紙を調べます
3. 縫い目のない装飾は、単純な立体に置き換えて考えます。立方体は角、円柱は上下と目立たない側面、球は側面を一周です
4. UV Editing ワークスペースで A で全選択し、UV > 展開 > アングルベース(Angle Based)を実行します
5. 不要な UV マップスロットを消します(オブジェクトデータタブ > UV マップ > -)
6. UV ストレッチを見ながら、Mio3 UV で直線化します(グリッド化、矩形、ストレート、整列)
7. 端をピン留め(P)して内側を展開し直し、歪みを抜きます
8. 大きさをそろえ(テクセル密度の Get → Set)、向きを合わせ、パディングを空けて配置します
9. ミラーモディファイアー > データ > ミラー U(Mirror U)で左右の UV を重ね、中心線にそろえます
10. UV エディターのオーバーレイ > タイル数(Tiles)で正方形を増やし、パーツ群ごとに詰めます

### 設定値
- 【画面】今回は縦に 6 タイルです
- 【話者】前側の UV は右に、後ろ側は左にそろえると見た目どおりになります

### 判断基準
- 【話者】直線にするのは、線が入る所と UV の端です。隙間が減って解像度が上がり、ジャギーも減ります
- 【話者】曲線に近い辺は、あえて直線にせず歪みを減らします
- 【話者】格子状の部分はグリッド化、三角面が混じる部分は四隅を選んで矩形、下が波打つフリルは上辺だけストレートで直線にします
- 【話者】UV ストレッチで濃い青ならきれいです。黄色や緑は歪みですが、柄の都合でわずかな歪みは許容します
- 【話者】UV の上下はモデルの上下に合わせます。近いパーツはまとめて配置します

### 落とし穴
- 【話者】展開の失敗の多くは、シームの入れ忘れや途切れです。次に疑うのは、非多様体、重なった頂点、面の向きです
- 【話者】エラーのある UV が複数スロットにあると、Blender が落ちることがあります
- 【話者】矩形は、UV が斜めのときに失敗することがあります。失敗した所だけピン留めを解除して直します
- 要確認: Mio3 UV の日本語 UI 表記です(「グリッド化」「矩形」「ストレート」は Gridify / Rectify / Straight にあたります)
- 要確認: 「3D に基づく大きさ」のボタン名です
- 要確認: パディング表示ボタンの位置です
- 要確認: Shift+C で 2D カーソルを中央へ移す操作です
- 要確認: タイル数の X / Y のどちらが縦かです

### 開く場所
- UV エディター右上 > オーバーレイ > UV ストレッチ(UV Stretch)/ 変形後の辺(Modified Edges)/ タイル数
- UV エディター > サイドバー(N) > Mio3 UV タブ
- 編集 > プリファレンス > エクステンションを入手(Get Extensions)> Mio3 UV

## 工程 4: ハイモデル(スカルプト)

### 手順(Blender)
1. ローモデルを Shift+D で複製し、複製の方をハイモデル用にします
2. ミラーモディファイアーを適用します
3. モディファイアーを追加 > 生成 > マルチレゾリューション(Multiresolution)で、細分化 / リニアを押します
4. スカルプトモードで照明を MatCap(グレー系)にし、対称(Symmetry)の X をオンにします
5. Shift のスムーズで、細分化で残った角やシワを消します
6. ドロー(Draw)で大きなシワを描きます(Ctrl で逆向き)。根元はスムーズでなじませます
7. ドローシャープ(Draw Sharp)で鋭い山や溝を、クリースシャープ(Crease Sharp)で深い溝を、グラブ(Grab)でカーブを調整します
8. 描き直したい所は、マルチレゾディスプレイスメント消しゴム(Multires Displacement Eraser)で戻します
9. 一段落したらマルチレゾリューションを適用し、Dyntopo をオンにして、密度(Density)ブラシで割りを直したり増やしたりします
10. 描くときは Dyntopo をオフにします
11. 硬いパーツは、ベベルやサブディビジョンで仕上げます

### 手順(ZBrush)
1. GoB か FBX で持ち込みます
2. ベーシックマテリアル(BasicMaterial)にし、サブツール(SubTool) > 複製(Duplicate)をします
3. シンメトリ有効(X)をオンにし、ジオメトリ > ZRemesher → ディバイド(Divide)を 2〜3 回かけます
4. スムーズとポリッシュ系で磨き、スタンダード(Standard)、SK クロス、SK スラッシュでシワを描きます。ムーブ(Move)で形を整えます

### 設定値
- 【話者】ローポリ寄りで角が丸まりすぎるときは、リニアを 2〜3 回かけてから細分化します。講座のスカートは細分化 3 回です
- 【画面】Dyntopo のディテールタイプは「相対ディテール」(Relative Detail)です
- 【話者】講座の衣装のハイモデルは合計約 2,000 万ポリゴンです

### 判断基準
- 【話者】布は ZBrush、硬いパーツは Blender で作ります。Blender は数百万ポリゴンを超えると重くなるので、パーツを分けて負荷を減らします
- 【話者】実物の服を見て、シワが入る所と入らない所を考えてから描きます。大きな凹凸から始めて細部へ進みます

### 落とし穴
- 【話者】ポリゴンの角やシワはベイクで拾われるため、描く前に表面を磨きます
- 【事実】Dyntopo はマルチレゾリューションが付いたままでは使えません。適用すると細分化レベルは消えます
- 【話者】Dyntopo をオンのまま描くと、アーティファクトが出やすくなります
- 【話者】マルチレゾリューションでシャープな角が丸まる場合は、パーツを分離(P)するか、サブディビジョンサーフェスとクリース(Shift+E)を適用してからマルチレゾリューションをかけます(質疑応答より)
- 要確認: 密度ブラシは旧 Simplify ブラシにあたるとみられます
- 要確認: 仕上げの「フラット化ブラシ」の名称です
- 要確認: ZBrush の日本語 UI 表記です
- 要確認: SK ブラシは ArtStation 配布の SK_Pack とみられます

### 開く場所
- プロパティエディター > モディファイアータブ > モディファイアーを追加 > 生成 > マルチレゾリューション
- ビューポートシェーディングのポップオーバー > 照明 > MatCap
- スカルプトモードのヘッダー > 対称 / Dyntopo
- ZBrush > ジオメトリ > ZRemesher / ディバイド

## 工程 5: ベイク(Blender でのパーツ分け + SP)

### 手順
1. ローモデルを複製し(本番用は残します)、ノーマル用のパーツ分けをします。L でリンク選択し、メッシュ > 分離 > 選択(P)で分けます
2. ハイモデルも同じ単位で分け、名前をそろえて `_low` / `_high` を付けます。コレクション(例: リボン_Normal の下にリボン_low とリボン_high)で整理します
3. AO 用のパーツ分けをします。基本は 1 オブジェクトにまとめ、表示を切り替えるパーツと大きく揺れるパーツだけを分離します
4. 元モデルと同じ位置にあるか、マテリアル名と割り当てが正しいかを確かめます
5. ロー用・ハイ用・AO 用を別々の FBX で書き出します
6. SP で、ロー用 FBX からノーマル用プロジェクトを作ります
7. テクスチャセットの設定 > メッシュマップをベイク(Bake Mesh Maps)を開き、ハイポリメッシュを指定します。最大距離、マッチ、アンチエイリアスを設定し、Normal だけを Alt+クリックでオンにして焼きます
8. 出力テンプレートに Normal OpenGL を入れて書き出します
9. AO 用 FBX から AO 用プロジェクトを作り、メッシュマップの Normal 欄に書き出したノーマルを入れます。Ambient occlusion だけをオンにして焼きます
10. AO チャンネルを追加(ミキシング「置き換え」)し、焼いた AO を塗りつぶしレイヤーで敷きます。その上のペイントレイヤー(パススルー)で、指先ツール・ブラシ・消しゴムを使ってレタッチします
11. AO をグレーのテンプレートで仮に書き出します

### 設定値
- 【話者】FBX は「選択したオブジェクト」、スケールを適用「すべてFBX」(FBX All)、ジオメトリ「三角面化」(Triangulate Faces)にします
- 【話者】SP のドキュメント解像度は 4096 です(簡単なモデルなら 2048)。法線マップ形式は Unity なら OpenGL、Unreal なら DirectX です
- 【話者】前面の最大距離は、赤いはみ出しが消えるまで上げます。背面の最大距離も、くぼみが取れるまで少し上げます
- 【話者】マッチは「メッシュ名別」(By Mesh Name)、アンチエイリアスは 4 か 8 です(講座では 8)
- 【話者】AO は、セルフオクルージョンを「同じメッシュ名のみ」(Only Same Mesh Name)にします
- 【話者】書き出しは PNG、4096 か 2048、パディング「拡張 + 透明」(Dilation + transparent)です

### 判断基準
- 【話者】ノーマル用は交差をなくすために分けます。AO 用は、切り替えや揺れで影だけが残るのを防ぐために分けます
- 【話者】ベイク用の 2 プロジェクトは素材作りの場です。完成品はテクスチャ用プロジェクトです
- 【話者】エラーへの対処は 3 段階です
  1. ポリゴンに沿った筋が出るときは、重ねた UV を 1 つ残して G → X → 1 で横に 1 タイルずらします(UV を横に並べているなら Y)。ノーマル用と AO 用の両方で行います
  2. 欠けるときは、まず最大距離を調整します。次にハイモデルの高低差をグラブで抑えるか、ケージモデルを作ります
  3. 最後の手段として、ペイントレイヤー(パススルー)と指先ツール(チャンネルを normal のみ)で手直しします

### 落とし穴
- 【話者】本番用のローモデルを分けてしまうと、Unity 用のモデルまでバラバラになります
- 【話者】名前は、コピーして末尾だけ変えると確実です
- 【事実】AO 用プロジェクトにはハイモデルを読み込みません。凹凸はノーマル経由で取り込みます
- 【話者】AO は、テクスチャで凹凸を足したあとに焼き直します
- 【話者】レタッチ用のペイントレイヤーは、初期状態の乗算のままだと二重にかかります。パススルーにします
- 要確認: ケージの方式を「距離ベース」から変える欄の表記と読み込み手順です(該当音声が誤認識で失われています)
- 要確認: AO チャンネルの UV パディング設定です

- Blender: アウトライナー > 右クリック > 新規コレクション(New Collection)
- Blender: ファイル > エクスポート > FBX (.fbx)

- SP: ファイル > テクスチャを書き出し(Ctrl+Shift+E) > 出力テンプレート(RGB / グレー)

## 工程 6: テクスチャ(SP)

### 手順
1. ロー用 FBX でテクスチャ用プロジェクトを作ります。複数 UV タイルを使う場合は、UV タイルのワークフローにチェックします
2. チャンネルを追加します(Ambient occlusion。必要に応じて Opacity、Emissive)。標準ミキシングと AO ミキシングを「置き換え」、UV パディングを「3D スペースネイバー」にします
3. メッシュマップの Normal と AO に焼いた画像を入れ、Normal・AO・ID のチェックを外して残りを焼きます(マテリアルごとに行います)
4. 環境マップを見やすいものにし、シェーダーを pbr-metal-rough-with-alpha-blending にします
5. 最下層に塗りつぶしレイヤーを作り、ベースカラーを白にして、Normal と AO を敷きます
6. 塗りつぶしレイヤー、黒のマスク、ペイントの順に作り、ポリゴン塗りつぶし(4 キー)の UV 単位で色分けします。ミラーフィルターで左右対称にし、フォルダーで整理します
7. 柄を貼ります。多色の SBSAR はレイヤーに直接入れ、単色の柄はマスクに入れます。歪んだら Blender で UV を直してメッシュを再読み込みします
8. ディテールを足します
   - 布端: マスクに UV Border 系のジェネレーターを入れ、Blur と Histogram Scan で整え、Height を上げます
   - 縫い目: パスとステッチ系ブラシで引き、Height を付けます
   - 繊維: マスクに繊維素材を入れて三面投影にし、Height を付けます
9. 足した凹凸をメッシュマップに反映します
   - ノーマルを書き出し、AO 用プロジェクトで AO を焼き直します
   - 書き出したノーマルをテクスチャ用のメッシュマップに入れ、World space normal と Curvature を焼き直します(Curvature は法線マップから生成)
   - 最後に Normal を元に戻します
10. ライティングを焼き込みます。AO(乗算)、Curvature、Position、Light × 2、Baked Lighting Environment の順です
11. 質感を調整します。Roughness でツヤを付け、グランジで色ムラ、繊維の重ね、Blur Slope を使い、縫い目の食い込みを作ります
12. 出力テンプレートで最終書き出しをします。白黒はグレー、カラーは RGB、ベースカラーは RGB+A です

### 設定値
- 【話者】解像度は 4096 です(重い場合やシンプルな衣装なら 2048)。法線マップ形式は OpenGL です
- 【話者】アンチエイリアスは 4 か 8 です
- 【話者】Curvature のジェネレーターは、少しブラーをかけて透明度を上げ、薄く入れます。メッシュマップの Curvature を塗りつぶしに入れ、オーバーレイで重ねてレベル補正で強さを変える方法もあります
- 【話者】Light ジェネレーターは前後 2 つ重ね、加算とレベルで反転させて影にします
- 【話者】Baked Lighting はパススルーにして弱めにかけます。色や数を変えたいときは Baked Lighting Stylized を使います

### 判断基準
- 【話者】UV のミスに気づきやすい柄を早めに入れます
- 【話者】トゥーンシェーダー(lilToon)向けでは、マテリアル表示ではなくベースカラー表示で焼き込み量を判断します
- 【話者】質感は「凹凸」「焼き込んだ影」「ツヤ」の 3 要素で作ります。奥まった所は Roughness を上げて暗くし、角は下げてハイライトにします
- 【話者】色ムラは、気づかれない程度にとどめます。何より実物の服を観察することが大事です
- 【話者】完全なイラスト調なら、ハイモデルとベイクを省いてペイントソフトで塗ります
- 【話者】よく使う機能として、ハイライトに Metal Edge Wear、カラバリに HSL とグラディエントが挙げられていました

### 落とし穴
- 【事実】ミキシングを「置き換え」にすると、メッシュマップのノーマルと AO が自動では効かなくなります。最下層の敷きレイヤーが必要です
- 【事実】テクスチャセットの設定は、マテリアルごとに独立しています
- 【話者】SP 上の Height はジェネレーターに反映されません。先にメッシュマップへ反映させます
- 【話者】透明な空レイヤーに直接描くやり方は、SP では基本使いません
- 要確認: 「UV タイルのワークフローを使用」の日本語表記です
- 要確認: 環境マップ「スタジオホワイトソフト」の正式名です
- 要確認: ミラーフィルターの名称です
- 要確認: メッシュ再読み込みのメニュー経路です
- 要確認: UV Border 系ジェネレーターの正式名です
- 要確認: Curvature の「法線マップから生成」の日本語表記です
- 要確認: Baked Lighting の環境マップ「オートモーティブニュートラル」の正式名です

### 開く場所
- テクスチャセットの設定 > チャンネル + / ミキシング / UV パディング / メッシュマップ
- 表示設定(Display Settings) > 環境マップ、シェーダー設定(Shader Settings)
- レイヤーパネル > 塗りつぶしレイヤーを追加 > 右クリック > 黒のマスクを追加 / ペイントを追加 / ジェネレーターを追加 / フィルターを追加
- ツールバー > ポリゴン塗りつぶし(Polygon Fill、4)、指先ツール(Smudge)、パスツール(Path)

## 工程 7: ボーンとウェイト(Blender)

### 手順
1. キャラクターのアーマチュアで不要なボーンを削除します(編集モード > X)
2. 親ボーンの先端から E → Y で押し出し、接続を外して根元を移動し、名前を付けます。最後に、ウェイトなしのエンドボーンを 1 本足します
3. 分岐する揺れ物は、親ボーンから押し出した根元に、まとめ用の空の骨を置いて枝分かれさせます
4. スカートは、ヒップからまとめ用の空の骨を出し、傘の骨状に左側だけ(`_L`)作ります。細分化、エンドボーン、対称化(Symmetrize)の順に進めます
5. 軸(Axes)を表示し、ロールを再計算(Recalculate Roll) > グローバル +Z 軸を実行します。ポーズモード(ローカル、個々の原点)で R → X を回して確かめます。うまくいかない骨は Ctrl+R で手動で直します
6. 衣装を全部選び、最後にアーマチュアを選んで、Ctrl+P > 空のグループで(With Empty Groups)にします
7. データ転送(Data Transfer)モディファイアーを付けます(ソースは素体、頂点データ > 頂点グループ > 最近接面の補間)。アーマチュアより上に移動し、選択にコピーして、1 つずつ適用します
8. 単純な揺れ物は、ウェイトペイントのグラデーション(自動正規化オン)で下から奪うように付けます。スムーズ(全グループ)でならします
9. 複雑な揺れ物(スカート、肩のフリル)は簡易モデルを使います
   - ボーンと同じくらいの頂点数でモデルを作ります
   - 頂点選択 → ウェイト 1.0 → 割り当て(Assign)でウェイトを付けます
   - 本番の衣装にデータ転送します。転送範囲は専用の頂点グループで限定します
10. チェックをします。関節を曲げ、ひねり、接続を外して大きく移動し、揺れ骨は上げたり左右に揺らしたりします
11. 数値の表(yuzuWeightEditor など)で、親から順に、関係ないグループをロックしながら調整します
12. 仕上げに、クリーン(Clean、全グループ)、合計を制限(Limit Total、全グループ、制限 4)、すべてを正規化(Normalize All)をかけ、骨を動かして再確認します

### 設定値
- 【話者】調整の順番は、胴体ならヒップ → スパイン → チェスト、腕ならチェスト → ショルダー → アッパーアーム → ロワーアームです
- 【事実】Unity では、1 頂点に割り当てられるウェイトは 4 グループまでです
- 【話者】ボーン表示はスティック(Stick)にし、最前面(In Front)をオンにします

### 判断基準
- 【話者】編集中のボーンとその親以外はロックし、2 つの間だけで取り合います。スカートは隣接するボーン同士の調整も要ります
- 【話者】表裏のあるパーツは、表と裏を同じ値にします。それでも貫通する所は、頂点の位置や厚みで直します
- 【話者】肘や膝の貫通は、頂点を素体から少し離すか、関節のエッジを素体に近づけて直します
- 【話者】ブラシより数値の表の方が、狙った値になります

### 落とし穴
- 【話者】揺れ骨にエンドボーンがないと、Unity で先端が無視されることがあります
- 【事実】接続が付いたまま根元を動かすと、親ボーンまで動きます
- 【話者】データ転送をアーマチュアより下に置いたまま適用しないようにします
- 【話者】ロックをしないと、関係ないグループの値が勝手に変わり、調整が終わらなくなります
- 【話者】合計の制限と正規化はウェイトを少し変えます。調整中にもときどきかけて確かめます
- 【話者】別のアバターへ対応するときは、揺れ物の頂点グループをロックしてから転送すると、揺れ物のウェイトを流用できます。関節のエッジ数はアバターで違います(質疑応答より)
- 要確認: 揺れ骨の命名例です
- 要確認: グラデーションで塗るときのボーンの選び方です
- 要確認: Lazy Weight Tool という名称です

### 開く場所
- ボーンタブ > 関係(Relations) > 接続(Connected)
- オブジェクトデータタブ(アーマチュア) > ビューポート表示 > 表示方法 / 軸 / 最前面
- アーマチュア > ボーンロール > ロールを再計算(Shift+N)

## 工程 8: Unity + lilToon での仕上げ

### 手順
1. 衣装メッシュとアーマチュアだけを選び、FBX で書き出します。設定は、選択したオブジェクト、すべてFBX、三角面化、リーフボーン追加(Add Leaf Bones)オフです
2. VRChat 向け Unity 2022 系に lilToon と VRChat SDK を入れておきます
3. Material / Texture / FBX のフォルダーを作ってインポートします
4. FBX の Model タブで Read/Write をオン、Blend Shape Normals を None にして Apply します
5. Materials タブ > Extract Materials でマテリアルを取り出します
6. シェーダーを lilToon に変え、Directional Light の色を白にします
7. lilToon を設定します
   - メインカラー
   - 影設定: 影をオン、AO マップ
   - ノーマルマップ設定: Fix Now を押します
   - リムライト: 白、マスクに AO
   - 光沢設定: 反射をオン、滑らかさにグロスマップ、タイプはリアル、環境光の反射に HDRI のキューブマップと Override
   - リムシェード
   - マットキャップ: 金属用、メタリックのマスク
8. マテリアルを複製して、カラバリを作ります
9. Unity と VRChat で確かめ、違和感があれば前の工程に戻ります

### 設定値
- 【話者】AO の範囲は影設定の 1st の Min / Max で調整します(要確認)。Min を上げると広がり、Max を下げると狭まります
- 【話者】反射率は弱めにし、リムシェードはグレー程度で弱く入れます
- 【事実】HDRI は、Texture Shape を 2D から Cube にして Apply します

### 判断基準
- 【話者】Blender や SP できれいに見えても、Unity で印象が変わります。最終的に使う場所で確かめます
- 【話者】VRChat はポストプロセスが強い環境が多いので、オンとオフの両方で確かめます
- 【話者】気になった所はスクリーンショットとメモを残し、前の工程で直します

### 落とし穴
- 【事実】リーフボーン追加がオンのままだと、余分なボーンが付きます
- 【事実】グロスマップはラフネスの白黒反転です。SP の Roughness をそのまま入れると逆になります
- 【事実】lilToon の各設定は、見出しのチェックをオンにしないと効きません
