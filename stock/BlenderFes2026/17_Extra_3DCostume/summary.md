# 【Blender Fes Extra】3D衣装の作り方 要点(アレイラさん、前半 + 後編)

- 全体は 7 工程で進みます。デザイン決め、モデリング、UV 展開、ハイモデル、ベイクとテクスチャ、ボーンとウェイト、Unity でのチェックです。最低限そろえるソフトは Blender と Substance 3D Painter で、VRChat 向けなら Unity が加わります
- デザインは三面図が基本です。T ポーズと A ポーズは、選ばなかった方のポーズでもデザイン画を確かめれば、どちらで描いてもかまいません
- 制作前に分析をします。実物の服の構造を調べ、ポリゴン数(今回は 8〜10 万)、形で作る所とテクスチャに任せる所、テクスチャの枚数を見積もります
- モデリングは「標準の立体を出す、頂点を増やす、動かす」の繰り返しです。三面図と合わないときは、正面・斜め、背面、側面の順に優先します
- 後工程のために、縫い目や材質の境目に辺を置き、角にシャープを付け、関節のエッジを素体に合わせておきます
- シームは、シャープの位置、服の縫い目(型紙)、目立たない側面に入れます。Mio3 UV で端を直線にし、今回は 6 枚分のタイルに詰めています
- ハイモデルは、表面を磨いてから大きなシワ、鋭いシワの順に描きます。マルチレゾリューションを使い、仕上げにダイナトポの密度ブラシで割りを直します
- ベイクは 3 プロジェクトで行います(ノーマル用、AO 用、テクスチャ用)。ノーマル用は交差をなくすため、AO 用は影を残さないためにパーツを分け、`_low` / `_high` の名前で対応付けます
- テクスチャは、塗りつぶしレイヤーと黒マスクで色分けします。布端、縫い目、繊維で凹凸を足し、トゥーン向けに光と影をベースカラーへ焼き込みます
- ウェイトは素体からデータ転送します。揺れ物はグラデーションか簡易モデル経由で付け、数値の表を使って親子 2 つの間だけで取り合います
- Unity と lilToon では、影、AO、ノーマル、リム、反射を設定します。違和感があれば前の工程に戻ります。苦手な工程は途中のモデルで先に試すのが講師のおすすめです
